# 행발 기록 도우미

행동특성 및 종합의견(행발)·자율·동아리·진로·교과발달 문장을 **클릭해서 학생에게 넣는** 웹페이지.
두 가지로 쓸 수 있다.
- **웹앱(추천)**: 구글 Apps Script로 배포 → 주소 하나로 학교·집·휴대폰 어디서나, 기록은 내 구글 드라이브의 비공개 시트에 저장.
- **파일로**: `index.html`을 더블클릭 → 그 PC 브라우저에만 저장.

## 웹앱 설치 (처음 한 번)
1. https://script.google.com → **새 프로젝트**, 이름 `행발 기록 도우미`.
2. `Code.gs` 내용을 지우고 저장소의 `haengbal/Code.gs`를 통째로 붙여 넣기.
3. 왼쪽 **파일 +** → **HTML** → 이름 `Index`(확장자 없이) → 안의 내용을 지우고 `haengbal/index.html`을 통째로 붙여 넣기 → 저장(Ctrl+S).
4. 오른쪽 위 **배포 → 새 배포** → 톱니바퀴에서 **웹 앱** → 실행: **나**, 액세스 권한: **나만** → 배포 → 권한 허용.
5. 나온 **웹 앱 주소**를 북마크. 처음 열면 드라이브에 `행발 기록 도우미 (데이터)` 시트가 자동으로 생긴다.
   지난 기록은 **백업 불러오기**로 넣으면 시트에도 올라간다.

갱신: 화면(`index.html`)이나 `Code.gs`가 바뀌면 해당 파일을 다시 붙여 넣고 **배포 → 배포 관리 → ✏️ → 버전: 새 버전 → 배포**.
주소는 그대로다. `Code.gs`가 바뀌면 `API_VERSION`이 올라가고 화면이 '다시 붙여 넣기'를 알려 준다.

### 빠르기
클릭은 화면에 바로 반영되고(시트를 기다리지 않음), 바뀐 학생·영역만 0.7초 뒤 한꺼번에 시트로 보낸다.
오른쪽 위에 `저장 중… → ✓ 시트에 저장됨`이 뜨고, 실패하면 저절로 다시 시도한다(빨간 글씨를 누르면 바로).
저장 중에 창을 닫으려 하면 경고가 뜬다. 다른 기기에서 고친 내용은 그 화면으로 돌아올 때 받아 온다
(두 기기에서 **같은 학생**을 동시에 고치면 나중에 저장한 쪽이 남는다).

### 시트
`학년도`·`기록`·`추가문장`·`숨긴문장` 탭. `기록` 탭에서 학년도·영역·번호·이름·최종 문장을 바로 볼 수 있다.
시트는 보기용으로만 쓰고 고치기는 화면에서 한다(숨긴 A·B열이 실제 데이터).

## 쓰는 법
1. **명단** → `번호 이름`을 한 줄에 한 명(엑셀·나이스에서 두 열 복사해 붙여 넣기 가능).
2. 왼쪽에서 학생 → 가운데 문장 클릭 = 그 학생에게 추가, 다시 클릭 = 빼기. ↑↓ 키로 학생 이동, `/`로 검색.
3. 오른쪽에서 순서(↑↓)·빼기(✕)·문장 직접 고치기(클릭해서 수정), 직접 쓴 문장 추가.
   최종 문장은 글자 수와 NEIS 바이트(한글 3B)를 같이 보여 준다.
4. **학급 전체 보기** → 학생별 복사, 엑셀용 표 복사, CSV 저장.
5. **문장 추가** → 영역·묶음(새 묶음도 가능)을 골라 여러 줄을 한꺼번에 붙여 넣기. 기본 문장은 '숨기기' 가능.
6. 학년 말 **올해 확정 저장** → 읽기 전용으로 잠기고, 위 '학년도'에서 그 해를 고르면 언제든 다시 본다.
   **+ 새 학년도**로 다음 해를 시작한다.

## 저장
- 기록은 그 PC 브라우저(localStorage)에 자동 저장된다. 브라우저 기록 삭제·다른 PC에 대비해 **백업 저장**(JSON)을 가끔 받아 두고,
  다른 PC에서는 **백업 불러오기**로 옮긴다.
- 학생 이름·기록은 저장소에 절대 넣지 않는다(백업 파일도 커밋 금지).

## 문장 은행 다시 만들기
엑셀(한셀 저장본 포함)의 `행발기준`·`추가문장풀`·`자율활동`·`동아리`·`진로`·`교과발달` 시트에서 뽑는다.

```
python haengbal/build_bank.py 행발.xlsx                                  # index.html의 문장 은행 갱신(이름 없음)
python haengbal/build_bank.py 행발.xlsx --year 2024 --backup 2024.json   # 그 해 배치(A~G열 + 행발최종 K열~)를 백업 파일로
```
