# 칠교 놀이터

아이들이 칠교판 조각(최대 2벌, 14조각)을 끌어다 그림자 모양을 채우는 100단계 놀이.
`index.html` 한 파일로 돌아간다(브라우저에서 바로 열면 된다).

## 놀이 방법
- 조각을 끌어다 그림자 위에 놓는다. 정답 자리 가까이 오면 쏙 들어맞고, 아니면 가까운 꼭짓점끼리 붙는다.
- 조각을 톡 누르면 돈다(쉬운 단계는 90°, 21단계부터 45°). 평행사변형은 **뒤집기** 버튼으로 뒤집는다.
- 그림자를 빈틈없이, 밖으로 삐져나오지 않게 다 채우면 성공 → 다음 단계가 열린다.
- **힌트**는 아직 비어 있는 자리 하나를 깜빡여 보여 준다(쓴 횟수가 기록에 남는다).

## 난이도
| 단계 | 조각 | 돌리기 | 조각 선 | 비고 |
|---|---|---|---|---|
| 1–8 | 2–3 | 90° | 모두 보임 | 조각이 처음부터 정답 방향 |
| 9–20 | 3–4 | 90° | 모두 보임 | |
| 21–35 | 4–5 | 45° | 모두 보임 | |
| 36–50 | 5–7 | 45° | 일부만 | 평행사변형 뒤집기, 50단계 = 칠교판 정사각형 |
| 51–70 | 7–9 | 45° | 없음 | 8조각부터 칠교판 2벌 |
| 71–90 | 10–12 | 45° | 없음 | 대칭 모양 섞임 |
| 91–100 | 13–14 | 45° | 없음 | 100단계 = 정사각형 두 개 |

## 순위표
- 이름(별명)을 넣고 놀이하면 단계별 최고 기록(초)이 저장된다.
- 순위: 연속으로 깬 단계가 많은 순 → 같으면 그 단계들의 최고 기록 합이 짧은 순.
- claude.ai 아티팩트로 열면 그 아티팩트의 공유 저장소(`scores` 컬렉션)에 기록이 모여, 같은 놀이판을 여는
  모든 기기에서 같은 순위표를 본다(기록하려면 Contributor 이상 권한). 그냥 파일로 열면 그 기기(localStorage)에만 저장된다.

## 문제 바꾸기
```bash
node games/tangram/generate_levels.mjs
```
정해진 씨앗으로 늘 같은 100단계를 만들고 `index.html`의 `LEVELS` 자리에 넣는다. 단계마다 조각 겹침·구멍·조각 수(칠교판 2벌 이내)를
검사하고, 하나라도 어기면 파일을 바꾸지 않는다. 씨앗이나 `plan()`의 난이도 표를 바꾸면 문제가 달라진다(이미 남은 기록과는 맞지 않게 된다).
