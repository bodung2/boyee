# 칠교 놀이터

아이들이 칠교판 조각(최대 2벌, 14조각)을 끌어다 그림자 모양을 채우는 100단계 놀이.
`index.html` 한 파일로 돌아간다(브라우저에서 바로 열면 된다).

## 놀이 방법
- 조각을 끌어다 그림자 위에 놓는다. 정답 자리 가까이 오면 쏙 들어맞고, 아니면 가까운 꼭짓점끼리 붙는다.
- 조각을 톡 누르면 돈다(쉬운 단계는 90°, 21단계부터 45°). 평행사변형은 **뒤집기** 버튼으로 뒤집는다.
- 그림자를 빈틈없이, 밖으로 삐져나오지 않게 다 채우면 성공 → 다음 단계가 열린다.
- **힌트**는 아직 비어 있는 자리 하나를 깜빡여 보여 준다(쓴 횟수가 기록에 남는다).

## 난이도
모든 단계가 조각 사이 선 없이 그림자만 보여 준다(칠교 놀이의 기본). 그림자는 조각들을 합친 바깥 테두리 하나로 그려
이음매가 비치지 않는다.

| 단계 | 조각 | 돌리기 | 비고 |
|---|---|---|---|
| 1–8 | 2–3 | 90° | 조각이 처음부터 정답 방향 |
| 9–20 | 3–4 | 90° | |
| 21–35 | 4–5 | 45° | |
| 36–50 | 5–7 | 45° | 평행사변형 뒤집기, 50단계 = 칠교판 정사각형 |
| 51–70 | 7–9 | 45° | 8조각부터 칠교판 2벌 |
| 71–90 | 10–12 | 45° | 대칭 모양 섞임 |
| 91–100 | 13–14 | 45° | 100단계 = 정사각형 두 개 |

## 순위표 — 어디서 여느냐에 따라
| 여는 곳 | 기록이 모이는 곳 | 누가 자동으로 기록되나 |
|---|---|---|
| **구글 Apps Script 웹앱 (권장)** | 선생님 구글 드라이브의 `칠교 놀이터 순위표` 시트 | 링크를 연 모든 아이(로그인 없이) |
| claude.ai 아티팩트 | 아티팩트 공유 저장소(`scores`) | Contributor 이상 계정만. 공개 링크 방문자는 기록 코드로 |
| 파일 그대로 | 그 기기(localStorage) | 없음(기록 코드만) |

- 이름(아이디)을 넣으면 그 이름의 기록을 불러와 **이어서** 한다(다른 기기에서도). 로그인·비밀번호가 없으니 같은 이름은 누구나 이어 쓸 수 있다.
- 순위: 연속으로 깬 단계가 많은 순 → 같으면 그 단계들의 최고 기록 합이 짧은 순. 이름만 넣은 친구는 0단계로 보인다.
- **기록 코드** `[칠교:이름:깬 단계:시간 합:확인 4글자]`: claude.ai 링크에서 직접 못 쓴 기록을 옮기는 데 쓴다.
  Apps Script 웹앱에서는 순위표 → **이전 기록 가져오기**에 붙여 넣으면(여러 명 한꺼번에, 대화 통째로도) 그 단계까지 깬 것으로 이어서 한다.
  확인 글자로 숫자를 고친 코드는 거른다(페이지 소스를 보면 만들 수 있으니 장난 방지 수준).

## 구글 Apps Script 웹앱으로 올리기 (처음 한 번, 약 5분)
1. https://script.google.com → **새 프로젝트**. 이름은 `칠교 놀이터`.
2. 왼쪽 `Code.gs` 내용을 지우고 `games/tangram/apps_script/Code.gs`를 통째로 붙여 넣는다.
3. 파일 옆 **+** → **HTML** → 이름 `index` → 내용을 지우고 `games/tangram/index.html`을 통째로 붙여 넣는다. 저장(Ctrl+S).
4. 오른쪽 위 **배포 → 새 배포** → 톱니바퀴에서 **웹 앱** → 실행: **나** / 액세스 권한: **모든 사용자** → 배포.
5. 권한 허용 창: 계정 선택 → '확인되지 않은 앱'이면 **고급 → 칠교 놀이터(으)로 이동** → 허용. (선생님이 직접 만든 스크립트라 뜨는 경고)
6. 나온 **웹 앱 URL**이 아이들에게 줄 새 링크. 처음 기록이 들어오면 드라이브에 `칠교 놀이터 순위표` 시트가 생긴다.
7. 기존 기록 옮기기: 새 링크 → 순위표 → **이전 기록 가져오기** → 코드들을 붙여 넣고 올리기.

코드를 고친 뒤에는 2·3번처럼 다시 붙여 넣고 **배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포**(링크는 그대로).
아이를 지우려면 시트에서 그 줄을 지운다.

## 문제 바꾸기
```bash
node games/tangram/generate_levels.mjs
```
정해진 씨앗으로 늘 같은 100단계를 만들고 `index.html`의 `LEVELS` 자리에 넣는다. 단계마다 조각 겹침·구멍·조각 수(칠교판 2벌 이내)를
검사하고, 하나라도 어기면 파일을 바꾸지 않는다. 씨앗이나 `plan()`의 난이도 표를 바꾸면 문제가 달라진다(이미 남은 기록과는 맞지 않게 된다).
