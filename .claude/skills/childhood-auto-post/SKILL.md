# 유아교육 정보성 글 — 완전 자동 발행 모드

이 스킬은 `early-childhood-insight-extraction`의 **자동 발행 버전**이다. 파이프라인이 매일 1회 호출한다. 여기서 만든 `post.json`은 아래 순서를 거쳐 **사람 검토 없이 네이버에 발행된다.**

1. 구조 검증
2. 일러스트 생성(ChatGPT 이미지, Codex)
3. Claude 팩트체크
4. ChatGPT 팩트체크(Codex)

호출 프롬프트가 알려주는 값:
- `TODAY`: 오늘 날짜(Asia/Seoul)
- `OUTPUT_DIR`: 결과 저장 폴더
- `HISTORY_FILE`: 유아 글 발행 이력(제목·URL·레인·클러스터·영역)
- `RELATED_HISTORY_FILES`: 교육 블로그 등 다른 발행 이력(브릿지 레인의 내부 링크 보완용, 없을 수 있음)
- `ILLUSTRATIONS`: 본문 일러스트 개수

부재 중 자동 실행이므로 질문하지 말고 스스로 판단해 끝까지 진행한다. 판단 근거는 `research_log`에 남긴다.

## 0. 최상위 원칙: 정확성 + 출처 + 발달 안전

**register 규율 (C-Rank 방어의 핵심)**
- 이 블로그는 '교육 정책·교직 실무' 전문 채널이다. '육아블로그'가 아니라 **'초등 교사·교육 전문가가 쓰는 유아교육'**으로 쓴다.
- 이유식·수면·육아템 리뷰·생활 브이로그는 쓰지 않는다.
- 각 글에 **'초등 교사 관점' 문단을 1개 이상** 넣는다. 이 유아기 발달이 초등에서 어떻게 이어지는지를 쓴다.

**발달 안전 가드레일 (절대 준수)**
- **진단·판정 표현 금지:** '정상/지연', '몇 개월엔 이걸 통과해야', '이걸 못하면 발달이 늦음' 식으로 쓰지 않는다. 발달은 넓은 개인차 속의 **진행경로(진입·발달·확장)**로 서술한다.
- **검사 복제 금지:** K-DST·ASQ·Bayley·Denver 등 표준화 검사의 문항·그림·채점표·통과기준을 옮기지 않는다. 영역·구성개념만 참고한다.
- **조바심 조장 금지:** 놀이중심·개인차 존중·성인 상호작용을 강조한다. 지속적인 우려가 있으면 "워크북이 아니라 전문적 발달선별·평가가 먼저"라는 안내를 붙인다.
- **판매 링크 금지:** 워크북 판매·구매 링크나 쇼핑몰 주소를 절대 넣지 않는다(겸직 허가 전).

**자동 발행용 추가 규칙**
- 불확실하면 쓰지 않는다. '(확인 필요)', 'TBD', '○○' 같은 자리표시자가 남으면 발행이 막힌다.
- **경험 위조 금지:** "제가 해봤더니", "우리 반 아이가", "우리 아이는" 같은 개인 경험·사례를 지어내지 않는다. ✍️ 경험 블록은 만들지 않는다. 대신 검증 가능한 사실과 일반적인 현장 구조에 근거한 '교사 관점 해석'을 쓴다.
- 실존 아이·학교·기관 이야기와 실제 사진은 넣지 않는다.

## 1. 주제 선정: 클러스터 큐 + 우선순위 가중치 (요일 순환 없음)

`HISTORY_FILE`을 읽는다. Google Drive 도구가 있으면 콘텐츠 마스터 시트(ID `1uGQH525NEZjKnUR-tOshU61tbAv4Ws2-6CXukfAvHO0`)의 **"유아 콘텐츠 마스터" 탭**도 읽는다. 기존 "콘텐츠 마스터" 탭과 섞지 않는다.

**클러스터 규칙**
- 한 세부주제(클러스터)를 6~8편 몰아 쓰고 서로 내부 링크로 묶은 뒤 다음 클러스터로 넘어간다.
- 최근 이력의 `cluster` 값이 같은 글이 6편 미만이면 **그 클러스터를 이어서** 쓴다.
- 이어 쓸 때는 7영역 중 아직 단독 글이 없는 영역을 우선 채운다. 7영역은 M 감각·운동, E 실행기능, C 인지, N 초기수학, L 언어·문해, S 사회정서, A 적응·창의탐구다.
- 6~8편을 채웠거나 이력이 비어 있으면 레인 우선순위에 따라 새 클러스터를 연다.

**레인 (우선순위 순)**
- (A) 유아→초등 브릿지 [시그니처·최우선]: 현직 초등 담임이 역산한 유아기
- (B) 연령별 발달×교육 [트래픽 엔진]: 'N세 × 하위역량'
  - **나이→단계 전환 규칙:** 제목은 "N세 …?"로 유입시키되, 도입에서 "답은 나이 자름선이 아니다"로 프레임을 전환한다. 표의 축은 진입·발달·확장 단계로 잡고, 나이는 괄호 속 참고값("대략 4~5세에 흔함")으로만 쓴다. 연령 표를 통과 기준처럼 제시하지 않는다.
- (C) 누리과정·표준보육과정 '부모 번역'
- (D) 유아교육 정책·제도: 유보통합·무상보육·유아학비 등. 뉴스가 있을 때만 기회주의적으로 쓴다.
- (E) 가정 홈러닝: 집에서 하는 놀이·활동을 근거와 함께 안내한다. 자동 모드에서는 **활동지 파일 배포·다운로드 약속을 하지 않는다**(파일 배포는 별도 스킬 몫).
- (F) 유아교육 연구·이슈: 통념 반전. KICCE 등 연구를 쉽게 풀어낸다.

흥미·가치 점수(각 1점): ①검색 유입형 ②시의성 ③부모/교사 실질 도움 ④구체 수치·근거 ⑤전문성·인사이트. 같은 클러스터 안에서 그날 최고점 1편을 고른다. 이력과 사실상 같은 주제는 제외한다.

**34역량 분해 엔진**
- `assets/` 폴더에 SR의 「2-5세 유아용 워크북 핵심역량 설계연구」 파일(pdf/docx/md/txt)이 있으면 먼저 읽는다. 7영역·34하위역량과 진입-발달-확장 경로, 부록B 참고문헌 R1–R47을 주제 뼈대와 근거 지도로 쓴다.
- 파일이 없고 Google Drive 도구가 있으면 드라이브에서 찾는다.
- 둘 다 없으면 웹 1차 자료만으로 쓰고, **연구 내용을 인용한 척하지 않는다.**

## 2. 심층 리서치 (10개+ 정독 → 교차검증 → 종합)

최소 **10개 자료**를 WebFetch로 본문까지 읽는다.
- **1차 국내:** 2019 개정 누리과정·해설서, 제4차 어린이집 표준보육과정, 교육부·복지부 보도자료, 육아정책연구소(KICCE) 보고서
- **1차 국제:** NAEYC DAP(2020), Head Start ELOF, CDC 발달 이정표·Zubler et al.(Pediatrics 2022), WHO Nurturing Care
- **2차 해설·관점:** 교육 전문지, 전문가 칼럼, 상반된 견해(특히 F 레인)

교차검증 규칙:
- 날짜·수치·명칭(고시번호·연도·시행시점)을 교차검증한다. 상충하면 1차 출처를 따른다.
- 1차 출처로 확정되지 않는 내용은 쓰지 않는다.
- 정책 범위·시행시점(무상보육 대상 연령, 유보통합 단계 등)은 유동적이므로 최신 원문으로 확인한다.

**충실성 합격선.** 못 채우면 더 조사하고, 끝내 못 채우면 주제를 바꾼다.
- (a) 핵심 질문 5개와 근거 있는 답
- (b) 구체 수치·기준·발달 흐름 5개 이상, 각각 [근거+출처+연도]
- (c) 고시·조문·날짜 단위로 근거를 특정
- (d) 예외·개인차 단서 2개 이상
- (e) 1차 출처 원문 2개 이상
- (f) 유아 현장·가정 특수성 1개 이상

글을 다 쓴 뒤 "부모가 이 글만 읽고 오늘 아이와 무엇을 할지 알 수 있는가?"를 자문한다.

## 3. 작성 규칙

문체와 구조:
- 자연스러운 1인칭 교사 톤을 쓰되, 경험은 지어내지 않는다.
- **맨 앞:** 3줄 핵심 요약을 `<ol><li>…</li></ol>` 개조식 3항목으로 쓴다. 각 항목은 "~입니다"로 단정하고 핵심 수치를 1개 이상 넣는다. B형이면 2번 항목에 나이→단계 전환 문장을 넣는다.
- 그다음 도입 공감 2~3문장과 이모지 1개.
- **본문:** 1~5 넘버링. 1번은 '🧭 큰 그림' 챕터다. 소제목은 검색어형 질문으로 쓰고 첫 문장은 결론·정의문으로 쓴다. 모든 수치는 수치·출처·연도를 한 문장 안에 쓴다. 출처는 대괄호가 아니라 자연스러운 괄호로 쓴다(예: "…82%가 부정적이었습니다(교총 설문, 2025)").
- 💡 놓치면 손해 포인트 2~3개, 초등 교사 관점 문단 1개 이상을 넣는다. D형이면 마무리 직전에 🎓 장학사 시험 포인트를 넣는다(시험 범위와 겹칠 때만).
- 비교·단계별 기준이 3개 이상이면 표로 만든다(`<table border="1">`, 표 아래 개인차 단서). 키워드가 2개 이상인 챕터는 `<h3>▸ 키워드 | 핵심 결론</h3>`으로 나눈다.
- 제목류의 두 부분 구분자는 '|'를 쓴다.
- **마무리:** 한 줄 요약 + 같은 클러스터의 다음 글 예고.
- **🔗 함께 보면 좋은 글 2~3개:** `HISTORY_FILE`에서 URL이 있는 글만 쓴다. 우선순위는 같은 클러스터 → 같은 카테고리 순이다. A형은 `RELATED_HISTORY_FILES`의 취학준비·학부모 관련 글도 쓸 수 있다. 각 항목은 `「제목」 — 관련 이유` 다음 줄에 raw URL을 그대로 쓴다. URL이 있는 관련 글이 없으면 섹션을 통째로 뺀다.
- **해시태그 8~10개:** #유아교육 #누리과정 #연령별발달 #취학준비 등.
- **출처:** 2~3줄 압축형. 본문 인라인 출처는 필수로 유지한다.

**만들지 않는 것:** ✍️ 경험 블록, 발행 전 체크리스트, "자동 생성 초안" 안내문, 출처 줄 선택 안내 문구, 나노바나나 프롬프트 섹션.

### HTML 서식 (흰 종이에 검은 글씨)
- 사용할 태그: `<h2>`, `<h3>`, `<p>`, `<ol>`, `<ul><li>`, `<table border="1">`, `<br>`, `<strong>`(챕터당 1개 이내).
- style, class, 색 지정은 쓰지 않는다.
- 제목(`title`)을 본문에 다시 쓰지 않는다.

### 이미지 자리
- 요약 카드: `<p>[[IMAGE:card]]</p>`를 정확히 1번 넣는다(보통 1번 챕터 뒤).
- 일러스트: `ILLUSTRATIONS`개만큼 `<p>[[IMAGE:illust_a]]</p>`, `<p>[[IMAGE:illust_b]]</p>`… 를 흐름에 맞게 분산한다. 첫 일러스트는 도입 직후 대표 장면, 나머지는 해당 문단 바로 뒤에 둔다.
- 대표 썸네일은 파이프라인이 글 맨 앞에 넣으므로 표시하지 않는다.

### 일러스트 프롬프트 (이미지 생성 AI용)
각 일러스트는 대응 문단의 핵심을 **그림 한 장으로 설명**해야 한다. 추상 상징은 쓰지 않는다.
- 영어로 쓴다: [구체 장소: 한국 가정 거실/유치원 교실] + [인물의 구체 행동] + [핵심 소품] + [따뜻한 파스텔 조명] + [cute flat vector illustration, 모든 일러스트 스타일 통일] + [wide 16:9 composition]
- 반드시 포함: "no text, no letters, no numbers, no logos, no watermark", "natural Korean home/early-childhood-education context", "generic people, not any real person or real building"
- 아이는 연령에 맞는 자연스러운 모습으로 그리고, 위험한 행동이나 안전하지 않은 장면은 넣지 않는다.

필드 규칙:
- `domain`: 34역량 영역 코드(M/E/C/N/L/S/A)다. 썸네일 배경 톤이 이 값으로 정해진다. 영역과 무관한 정책·브릿지 글이면 `null`로 둔다.
- `thumbnail.main_lines`: 질문형 제목을 3줄 이내, 각 줄 6~7자 내외로 끊는다.
- `claims`: 본문의 **모든** 수치·날짜·고시·명칭 사실을 넣는다(보통 8~20개). `quote`는 원문에서 실제로 복사한 문장이어야 한다.

저장 후 `python -c "import json;json.load(open('...',encoding='utf-8'))"`로 JSON을 검증한다. 마지막 응답은 "주제 / 레인·클러스터 / 자료 수 / 제목" 한 줄로 끝낸다.
