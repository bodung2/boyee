# 인생 대시보드 웹앱 (휴대폰·밖에서 보기)

휴대폰이나 다른 컴퓨터에서 여는 **나만 볼 수 있는 웹앱**입니다. 위쪽 탭이 두 개입니다.

| 탭 | 내용 | 어디서 오나 |
|---|---|---|
| 퀘스트 보드 | 오늘 예약 작업 상태·최근 14일 발행 기록(보기 전용) | 집 PC가 매시간 드라이브에 올리는 `quest_board.html` |
| 내 자산 | 💰금융 · 💵파이프라인(부가수입) · 🏠부동산 · 👨‍👩‍👧사람 · ✍️저작물 · 🎖직위 · 🏆수상·자격 기록, 순자산 추이, 다가오는 생일·기념일, 인생 연표 | 이 구글 계정의 비공개 시트(웹앱이 처음 열릴 때 자동으로 만듦) |

```
집 PC (매시간 QuestBoardRefresh, 23:40 QuestBoard)
  └─ python -m quest_board --upload → 드라이브에 quest_board.html(보드)과 life_dashboard_app.html(화면)을 올림
구글 Apps Script 웹앱 (webapp/Code.gs, '나만' 접근)
  ├─ 화면: 드라이브의 life_dashboard_app.html
  ├─ 내 자산 데이터: 비공개 시트 '인생 자산 대시보드 (웹앱 데이터)' — 추가·수정·삭제는 화면에서
  ├─ 시세: 국내·미국 주식/ETF = 구글 파이낸스(약 20분 지연, 국내는 네이버 증권으로 보충), 코인 = 업비트 원화 시세
  └─ 매일 16시(한국 시간) 순자산을 기록 → 추이 그래프 (구글 서버에서 돌아 PC가 꺼져 있어도 됨)
```

- **나만 볼 수 있습니다.** 드라이브 파일·시트는 공유하지 않고, 웹앱도 '나만'으로 배포하므로 그 구글 계정으로 로그인해야 열립니다.
  GitHub 저장소는 공개라서 **코드와 화면만** 올라가고, 자산·가족 정보는 어디에도 올라가지 않습니다.
  (여러 블로그 주소가 한 화면에 모이는 퀘스트 보드도 같은 이유로 GitHub Pages에 올리지 않습니다.)
- 퀘스트 보드는 PC가 꺼져 있으면 마지막으로 올린 화면이 보이고, 2시간 반 넘게 새로 올라오지 않았으면 맨 위에 알려 줍니다.
  예약 조정 버튼(시각 바꾸기·끄기·지금 실행)은 집 PC의 `scripts\quest_board.bat` 화면에만 있습니다.

## 1. 집 PC: 드라이브에 올라가는지 확인 (1분)

구글 블로거 자동화를 쓰고 있다면 이미 드라이브 권한이 있습니다. PowerShell에서:

```powershell
cd $HOME\boyee
git pull
.venv\Scripts\python.exe -m quest_board --upload
```

`휴대폰 웹앱용 화면을 구글 드라이브에 올렸습니다`와 `인생 대시보드 화면(webapp/app.html)을 새로 올렸습니다`가 나오면 됩니다.
`구글 드라이브 권한이 없습니다`가 나오면 `.venv\Scripts\python.exe -m blogger_autopost auth`로 다시 로그인한 뒤 다시 실행하세요.
이후에는 매시간 예약 작업(QuestBoardRefresh)이 알아서 올립니다(예약 등록:
`powershell -ExecutionPolicy Bypass -File scripts\setup_all_schedules.ps1 -Only QuestBoard,QuestBoardRefresh -NoInstall`).

## 2-A. 웹앱 처음 만들기 (5분)

**블로거 자동화에 로그인한 그 구글 계정**으로 진행합니다(드라이브 파일이 그 계정에 있습니다).

1. 컴퓨터 브라우저에서 <https://script.google.com> → **새 프로젝트**. 이름을 `인생 대시보드`로 바꿉니다.
2. 편집기의 내용을 모두 지우고, 저장소의 [`webapp/Code.gs`](../webapp/Code.gs) 내용을 통째로 붙여 넣은 뒤 저장(Ctrl+S).
3. 오른쪽 위 **배포 → 새 배포** → 톱니바퀴(유형 선택) → **웹 앱**.
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **나만** ← 꼭 확인
4. **배포** → **액세스 승인** → 계정 선택. '확인되지 않은 앱'이 나오면 **고급 → (프로젝트 이름)(으)로 이동(안전하지 않음)** → **허용**.
   내가 만든 스크립트가 내 드라이브·시트를 읽고 쓰고, 시세 사이트에 접속하고, 매일 16시 기록 예약을 만들겠다는 뜻입니다.
5. 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 휴대폰에서 열고 **홈 화면에 추가**합니다.

## 2-B. 이미 만든 웹앱을 새 코드로 바꾸기 (주소는 그대로)

예전에 '퀘스트 보드' 웹앱을 만들었다면 새로 만들 필요 없이 코드만 바꿉니다. **휴대폰에 저장한 주소가 그대로 유지됩니다.**

1. <https://script.google.com>에서 그 프로젝트를 엽니다.
2. `Code.gs`의 내용을 모두 지우고 저장소의 [`webapp/Code.gs`](../webapp/Code.gs)를 붙여 넣은 뒤 저장.
3. **배포 → 배포 관리** → 지금 배포 옆 **연필(수정)** → 버전: **새 버전** → **배포**.
   ('새 배포'를 누르면 주소가 바뀌니 '배포 관리'에서 고치세요.)
4. 권한을 새로 묻습니다(시트·시세 사이트·예약). 2-A의 4번처럼 허용합니다.

**코드를 다시 붙여 넣어야 하는 때:** 화면(탭·카드·그래프)만 바뀐 업데이트는 PC가 화면 파일을 다시 올리므로 할 일이 없습니다.
`webapp/Code.gs`가 바뀐 업데이트일 때만 2-B를 다시 하면 되고, 그때는 웹앱 화면 맨 위에 '웹앱 코드가 예전 버전입니다'라고 알려 줍니다.

## 3. 내 자산 쓰는 법

- 오른쪽 아래 **＋ 추가** → 분류를 고르고 적습니다. 카드를 누르면 수정·삭제할 수 있습니다.
- **금융:** 국내 주식·ETF(6자리 코드), 미국 주식·ETF(티커, 평단가는 달러), 코인(BTC 같은 기호)은 수량·평단가만 적으면 시세로 평가하고
  수익률을 보여 줍니다. 예적금·현금·연금·기타는 금액을 직접 적습니다(바뀌면 고쳐 주세요). 시세를 못 받는 종목은 '평가금액 직접 입력'을 쓰세요.
- **파이프라인(부가수입 통로):** 종류(광고·제휴·인세·강의·외주·콘텐츠 판매·배당·임대 등)·상태(운영 중·준비 중·쉬는 중·접음)·월 수입.
  '운영 중'인 것의 월 합계와 연 환산을 보여 줍니다. 순자산에는 더하지 않습니다.
- **부동산:** 매입가·현재 시세·대출 잔액. 시세는 자동이 아니라 가끔 직접 고칩니다.
- **사람:** 이름·관계·생일(양력)·기념일. 요약 화면에 60일 안의 생일·기념일이 D-day로 나옵니다.
- **저작물·직위·수상:** 날짜와 함께 남기면 '📜 연표'에 연도별로 모입니다. 직위는 종료일을 비워 두면 '지금 맡고 있는 일'로 보입니다.
- **순자산**(금융 + 부동산 − 대출)은 매일 16시에 기록되고, 이틀 이상 쌓이면 추이 그래프(1개월·3개월·1년·전체)가 나옵니다.
  화면을 열 때 시세가 30분 넘게 지났으면 알아서 새로 받고, '시세 새로고침'으로 바로 받을 수도 있습니다.
- **링크(선택):** 모든 분류에 링크 칸이 있습니다(블로그 관리 화면, 계좌, 문서, 증빙 등). 카드의 '링크'를 누르면 바로 열립니다.
- 데이터는 요약 화면 맨 아래 **시트 열기**로 원본 시트를 볼 수 있습니다(백업·엑셀로 내려받기). 시트의 열 이름·순서는 바꾸지 마세요.

## 4. 🏅 성장 탭 (6대 목표 점수)

신체 · 정신 · 기능·영감 · 사회 · 커리어 · 경제 기록을 **30대 후반 남성 중 상위 몇 %**인지로 바꿔, 모든 영역을 같은 공식으로 점수화합니다.

- **점수 = 10 × log₂(0.5 ÷ 상위 비율)**: 평균(상위 50%) 0점 · 상위 25% 10점 · 10% 23점 · 1% 56점.
- **비교군 바꾸기:** 성적표 위 '비교군 바꾸기'에서 성별(남자·여자·남녀 전체)과 나이대(20대~60대 이상·성인 전체)를 모든 영역에 한꺼번에, 또는 영역마다 따로 고릅니다.
  바뀌는 것은 **상위 %뿐**이고 점수는 늘 기본 비교군(남자·30대)으로 쌓입니다(비교군을 바꿔 점수를 부풀리지 못하게).
  근거: 생활시간조사 2024 연령별-성별(가사·돌봄, 교류·나눔) · 국민생활체육조사 2025 연령별 참여율(운동, 성별 없음) · PSS-10 규준 성별·연령(정신) ·
  가계금융복지조사 2025 가구주 연령별 순자산 중앙값(경제, 성별 없음) · 임금근로일자리 소득 2023 성별·연령별 평균(커리어 연봉, 남녀 20대·60대 이상은 추정).
  저축률·직업 지위·고용 안정성은 전체 기준을 그대로 씁니다.
  성적표에서 영역을 누르면 '비교군 평균' 표(비교군 평균 vs 나, 시작일부터)가 나오고, 비교군 고르기 화면에는 영역마다 수치가 가장 높은 군(정신은 스트레스가 가장 낮은 군)이 🏆로 표시됩니다.
- **종합 순위 · 가상 상대:** 성장 탭 맨 위 카드에 '비교군 ○○명 중 ○○등'과 성인 전체(20세 이상) 순위가 나옵니다.
  종합 표준점수 = 여섯 영역 누적 상위 %를 정규 점수로 바꿔 평균한 뒤 영역 사이 상관(ρ=0.3, 추정)을 고려해 다시 표준화(평균 50, 표준편차 10). 여섯 영역 가중치는 같고(각 1/6), 한 영역의 정규 점수는 ±3.23(상위 약 0.06%)에서 멈춰 만점 100점. 기록이 없거나 하위 16%보다 낮은 영역은 하위 16%(z −1)로 보아 최저 약 34.5점 — 어떤 기록을 더해도 종합 점수가 내려가지 않습니다.
  순위 = 종합 상위 % × 인구(2025 인구주택총조사 등록센서스 성·연령별 내국인). 순위와 상대는 '모든 영역' 비교군으로 계산합니다.
  가상 상대 100명(Lv.1 김평범 50점 → Lv.100 최끝판 86점)은 12가지 성향(주말 러너·마당발·짠테크·워커홀릭·가정의 중심·명상가·육각형·자산가·철인·살림 고수·인싸 직장인·자기관리왕)마다
  강점·약점이 다른 가상 인물이고, 종합 점수 순으로 하나씩 나옵니다(초반은 촘촘, 갈수록 간격이 넓음). 단계: 브론즈 1~20 · 실버 21~40 · 골드 41~60 · 플래티넘 61~80 · 다이아 81~95 · 마스터 96~100.
  이기면 다음 상대가 뜨고, 처음 이긴 날이 시트 한 항목(rivalrec)에 기록됩니다(점수에는 넣지 않음).
  **한 번 이긴 상대는 계속 이긴 것**으로 칩니다. 평균 페이스가 내려가 종합 점수가 떨어져도 이미 이긴 상대에게 다시 붙지 않고, 티어도 내려가지 않습니다. 최고 종합 점수를 함께 기록해 '지금 ○○점 · 최고 ○○점'으로 보여 줍니다.
  다음 상대와 영역별 대결(🟢 이김 · 🔴 짐)과 상대의 구체적인 숫자(운동 주 ○회, 월 보수 등 — 지금 비교군 기준)가 보이고, '상대 목록'에서 전체를 봅니다.
- **영역 상세:** 성적표에서 영역 줄을 누르면 그 영역의 쌓은 점수(흐름·돌파), 누적 상위 % 근거, 점수 내역 전체, 내 기록(눌러서 지우기)이 나옵니다.
- **신체 하루 습관:** 🚿 씻기(하루 1회) · 🪥 양치질(3회, '3·3·3 칫솔질') · 💊 영양제(2회) 권장 횟수를 채운 비율 × 0.5점(습관마다, 하루).
  세 가지를 매일 다 지키면 주 10.5점. ⏱ 기록 탭 맨 위 버튼을 누르면 1회씩 기록되고 오늘 횟수/권장 횟수가 보입니다.
- **기능·영감 기타:** 요리·놀이 같은 가사·돌봄 말고 직접 적는 활동(악기·그림·목공 등). 하루에 40분마다 1점, 하루 최대 2점(가사·돌봄 시간과 따로 셈).
- **사회 영역:** 친구 교류 시간이 아니라 **가족 관계**를 봅니다.
  매주 점수(상위 %) = 가족 관계 행동 횟수(👪 부모님 연락·방문 · 💑 배우자와 단둘이 · 🍚 가족 식사 · 🏡 기타 가족 일 · 가족 기념일 챙김, 한 번 = 1회) — 평균 주 5회(추정, 사회조사에 빈도 표가 없음).
  누적 상위 % = 가족 관계 행동 + 가족 형성(결혼 → 자녀 1명 → 2명 → 3명 이상 중 가장 높은 단계 하나: 결혼은 2025 인구주택총조사 성·연령별 배우자 있는 비율, 남자 30대 35.6% · 자녀는 2020 인구주택총조사(표본) 표 4 기혼여성 연령별 출생아 수로 — 30대 기혼 중 1명 이상 79.7%·2명 이상 43.4%·3명 이상 7.0% → 30대 남자 중 28.4%·15.5%·2.5%, 비교군 나이대마다 그 나이대 비율).
  친구·모임 시간은 상위 %에 넣지 않고 작은 기록 적립(30분 = 1점, 한 주 최대 3점)으로만. 기부·봉사는 점수에 넣지 않습니다.
- **성취는 깎이지 않는다(점검 원칙):** 기록·업적을 더해 쌓은 점수·누적 상위 %·종합 점수·순위가 내려가는 일이 없게 했습니다.
  ① 영역 누적 상위 % = 그 영역 지표 가운데 가장 좋은 것(평균을 내면 지표를 하나 더 적을 때 나빠질 수 있어서) ② 작은 기록 적립은 평균을 넘긴 주에도 모으고 점검·측정 1점은 주 상한 밖에서 따로
  ③ 같은 주 같은 영역 성취는 큰 것부터 전부·절반·0, 큰 돌파는 한 달 첫 번째만 +40 ④ 체력 등급 돌파는 가장 좋은 등급까지 오른 만큼(첫 측정 포함) ⑤
  종합 점수에서 기록 없는 영역은 하위 16%로 봅니다. 예외: 스트레스 점검·저축률·연봉처럼 '지금 상태를 재는' 값은 사실대로 반영해 나빠지면 내려갈 수 있습니다.
- **작은 기록 적립:** 평균에 못 미쳐 그 주 점수가 0이던 행동은 시작일부터 계속 모아, 정해 둔 양을 채울 때마다 1점(흐름 점수, 한 영역 한 주 최대 3점).
  1점 = 그 영역 '평균 한 주' 양의 약 1/8. 운동 30분(짧은 운동은 모아서 30분) · 가사·돌봄 60분(분리수거 1회 = 15분 → 4회) · 교류·나눔 30분 ·
  같은 주 같은 영역 세 번째부터의 성취(정신·커리어) 1회 · 스트레스 점검·체력 측정 1회(한 달 1회까지) · 저축한 달 1달.
  평균을 넘긴 주도 계속 모읍니다(기록을 더해 평균을 넘는 순간 적립이 사라져 점수가 줄던 일을 막기 위해). 한 주 3점을 넘친 양은 버리되 1점이 안 되는 만큼은 다음 주로 넘깁니다.
- **흐름 점수(매주):** 운동 횟수, 가사·돌봄 시간(요리·놀이·정리·설거지·청소·분리수거), 교류·나눔 시간, 정신 성취, 커리어 성취, 월 저축률(주 단위로 환산).
  한 영역 한 주 최대 56점(상위 1%)으로 모든 영역이 같습니다.
- **돌파 점수(한 번):** 순자산 구간, 파이프라인 월수입 구간, 직업(취직·전직·승진)·수상·자격·저작물(희소도별), 대회 완주, 체력 등급, 누적 봉사, 숙련 단계, 스트레스 점검 상위 구간. 같은 희소도의 4배.
- **과거의 성취도 나:** '오늘부터 시작하기'를 누른 날 이전 업적도 줄이지 않고 같은 점수로 들어갑니다('과거 업적' 표시만 붙음). 누적 점수는 줄지 않습니다.
- **커리어:** 결과만 기록합니다. 종류(업무 성과·본업 전문성·사람을 키운 성과·리더십·혁신·대외 활동)와 크기를 골라 정신과 같은 규칙으로 점수.
  '상위 %'는 지금 하고 있는 일의 직업 상위 %(아래 '직업 돌파'와 같은 계산). 학습 시간은 점수에 넣지 않습니다.
- **직업 돌파(취직·전직·승진):** 내 자산 → 직위 카드에 직업군·직위 수준·고용 형태·연봉을 적으면 그 일의 상위 %를 세 지표의 평균으로 냅니다.
  ① 지위 — 직업대분류 취업자 구성비(지역별고용조사 2026 상반기)를 '월 500만 원 이상 비율' 순으로 세우고, 직업군 안에서는 직위 수준(교원 직위 비율)으로 위치를 정함
  ② 연봉 — 같은 조사의 월 임금 분포를 30대 남자 평균 보수로 올린 분포(중앙 연 약 4,120만 원)
  ③ 안정성 — 공공부문 10% · 민간 정규직 37.5% · 자영업 등 22.7% · 비정규직 29.7% 순.
  날짜순으로 보며 '지금까지 가장 높은 직업'보다 오른 만큼만 돌파 점수가 더해집니다(같은 급 이직을 되풀이해도 늘지 않음).
  예: 교사(전문가 · 공공 · 연 5,800만) ≈ 상위 16% → 돌파 약 66점. 교사는 교감·교장이 되어도 직업군은 '전문가'로 두고 직위 수준만 바꿉니다.
- **두 갈래 점수:** 📈 흐름 점수(매일·매주 기록이 쌓인 것) + 🏆 돌파 점수(업적을 이룬 것). 성장 탭 맨 위에 따로 보이고, '최근 얻은 점수'에도 표시됩니다.
- **파이프라인 수익 기록:** 내 자산 → 파이프라인 카드를 열면 '💰 수익 기록'에 들어온 날과 금액을 적습니다.
  파이프라인마다 누적 수익이 1만·10만·100만·1,000만·1억 원을 넘는 날 돌파 점수가 생깁니다(시작일 이전 수익도 같은 점수).
- **자산 탭도 점수에 들어갑니다(돌파):** 직위·수상·자격·저작물(발표·수익), 순자산 구간, 파이프라인 월수입 합계 구간·누적 수익 구간,
  첫 내 집 마련(30대 주택 소유율 36%), 결혼·자녀(태어난 순서). 항목의 날짜가 점수 시작일
  이전이거나 비어 있으면 '과거 업적'으로 표시되지만 점수는 똑같습니다.
- **정신:** 영역(규율·감정·충동·회피·마음)과 크기(작은 승리 5 · 의미 있는 승리 15 · 큰 돌파 40, 월 1회)를 골라 기록.
  같은 주 같은 영역 반복은 절반 → 0. '상위 %'는 월 1회 스트레스 점검(PSS-10, 10문항)으로 냅니다.
- **정직한 기록:** 날짜는 오늘·어제만 고를 수 있습니다.
- **화면:** 쌓은 점수 육각형 + 상위 % 육각형, 주간·월간·누적 성적표, 최근 얻은 점수.
  누적은 시작일부터의 평균 페이스(운동 주당 횟수, 시간 하루 평균, 저축률·스트레스 점검 평균)에 지금까지 이룬 상태 지표를 더해, 영역마다 가장 좋은 지표로 냅니다.
  신체(체력 등급·대회 완주) · 기능(숙련 단계) · 사회(가족 관계 행동·결혼·자녀) · 커리어(지금 하는 일·수상·자격·저작물) · 경제(순자산·파이프라인 월수입, 순자산 기록이 없을 때만 내 집).
  각 줄 아래에 지표들과 상위 %가 좋은 순서로 보입니다(맨 앞이 그 영역의 상위 %).
  매주 처음 열 때 그 주의 누적 상위 %를 시트에 기록('누적 상위 % 기록(매주)' 표)하고, 지난 기록보다 좋아지면 ▲, 나빠지면 ▼로 보여 줍니다.
  **점수 기준·출처 보기**에 모든 기준 숫자와 출처, 근거 수준(공식 / 평균 공식·분포 추정 / 추정 / 해외 규준)이 나옵니다.
- 직위 카드에는 '직업군'·'직위 수준'·'고용 형태'·'연봉', 수상 카드에는 '수상 수준'·'자격 난이도' 칸이 있어 돌파 점수의 희소도를 정합니다.

## 화면 모드와 게임 화면
- 탭 줄 오른쪽 버튼(🌙/☀️/🖥)으로 **다크(기본, 게임풍) → 라이트 → 기기 설정 따라** 순서로 바뀝니다(이 기기에만 기억).
- 🏅 성장 탭 맨 위: **🥊 오늘의 대결**(나 vs 다음 상대, 줄다리기 게이지, 역전 길잡이 💡, 영역별 대결 자세히) → **🎯 오늘의 미션 3개**(역전 카드 영역 1 · 양치 · 다른 영역 1, 오늘 기록으로 자동 체크)
  → **티어 카드**(브론즈~마스터 방패와 다음 티어까지 진행 링, 순위와 지난주 대비 변화) → 인생 레벨 → 육각형(누적 보기에서는 다음 상대를 노란 점선으로 겹치고, 내 점은 🟢✓ 이김 · 🔴✕ 짐, 아래에 영역별 '나 ○% · 상대 ○%'와 ○승 ○패) → **🔥 연속 기록**(하루에 기록을 하나라도 남긴 날이 이어진 날 수 · 최고 기록 · 오늘 영역별 건수, 요일×6주 잔디 — 칸을 누르면 그날 기록).
- **상대 프로필:** 대결 카드와 상대 목록에 나이·성별·결혼·자녀·직업·집·생활 습관. 이미 정해진 영역별 상위 %와 같은 비교군 통계로 맞춰 정합니다
  (결혼·자녀 = 사회 상위 %를 성·연령별 배우자 있는 비율·자녀 비율 사다리에, 직업 = 커리어 상위 % 단계, 집 = 경제 상위 %, 생활 습관 = 상위 35% 안의 강한 영역, 약점 = 가장 약한 영역). 모두 가상 인물입니다.
  회사·연봉·집: 연봉 = 커리어 상위 %에 해당하는 월 보수 × 12(같은 비교군 임금 분포), 기업 규모 = 대기업 평균 월 613만·중소 307만(2024 임금근로일자리 소득)과 비교,
  회사는 실제 회사 이름(삼성전자·네이버·KB국민은행·김앤장·골드만삭스 서울지점 등). 창업자·개원의만은 회사가 곧 한 사람이라 실존 인물로 읽혀 회사를 밝히지 않음. 연봉은 통계 추정이라 그 회사 실제 급여와 무관.
  집은 그 지역·가격대를 대표하는 실제 단지 예시(시세는 추정, 실거래가와 다를 수 있음). 집 = 경제 상위 %의 순자산 → 자가 집값 ≈ 순자산 × 1.2(대출 포함, 추정), 전·월세 보증금 ≈ 순자산 × 0.6,
  지역은 실제 지역명을 집값 구간으로(한국부동산원 2026.10 서울 아파트 평균 13.7억·중위 11.1억, 수도권 주택 평균 6.8억, 지방 2.4억을 기준으로 한 추정 경계).
- **상대의 도발 한마디:** 대결 카드에 상대가 가장 강한 영역의 실제 숫자로 날마다 바뀌는 한마디(예: “월 보수 834만 원부터 시작이야.”).
- **📊 지난주 리포트:** 지난주 얻은 점수 · 기록한 날 · 이긴 상대, MVP 영역, 가장 성장한 영역(주간 누적 상위 % 기록 비교), 격파한 상대(일·월·화요일엔 펼쳐서).

- 점수가 오르면 대결 카드에 '+N'이 떠오르고, 상대를 이기면 **K.O.!** 화면(꽃가루·진동, 티어가 오르면 '○○ 승급!')이 잠깐 뜹니다. 미션·연출은 점수와 무관합니다.

## 5. ⏱ 기록 탭 (시작·끝만 누르는 시간 기록)

신체·정신·기능·영감처럼 매일 하는 일을 폰에서 바로 잽니다(커리어 성취·비정기 일은 🏅 성장에서 직접 기록).

1. **⏱ 기록** 탭에서 💪 신체 / 🧘 정신 / 🎨 기능·영감 중 하나를 누릅니다.
2. 하는 일을 고릅니다(예: 걷기·근력 운동 / 명상·미루던 일 하기 / 요리·놀이·청소·✏️ 기타). 메모는 선택이고, ✏️ 기타는 무엇을 하는지 꼭 적습니다.
3. **▶ 시작**을 누르고 일을 합니다. 진행 중인 일은 **화면 아래 막대**에 시계와 함께 계속 보입니다(다른 탭·새로고침·앱을 껐다 켜도).
   여러 일을 함께 시작할 수도 있습니다.
4. 끝나면 아래 막대의 **■ 끝**. 시작한 날짜와 걸린 분이 성장 기록으로 저장되고 점수에 바로 반영됩니다.
   - 신체 → 운동 기록(30분 이상이면 1회) · 기능·영감 → 가사·돌봄 시간 · 정신 → 고른 영역의 '작은 승리'(+5, 분도 함께 기록)
   - 분리수거는 시간 대신 **♻️ 1회 기록**을 누릅니다.
   - 5시간 넘게 켜져 있었으면(끝 누르기를 잊은 경우) 실제로 한 분을 물어봅니다. 잘못 켰으면 '기록하지 않고 취소'.
- **최근 기록 10개:** ⏱ 기록 탭 아래에 신체·정신·기능 기록이 최근 순으로 나오고, **시간 변경**(분·횟수·날짜)과 **삭제**를 바로 할 수 있습니다.
- **홈 화면에 바로 가기:** 웹앱 주소 끝에 `?tab=timer`를 붙여 열고(예: `https://script.google.com/macros/s/…/exec?tab=timer`),
  브라우저 메뉴의 '홈 화면에 추가'를 누르면 아이콘을 누르자마자 ⏱ 기록 화면이 열립니다.

- **주소 점검**(하루 한 번 자동, '지금 점검'): 🟢 열림 · 🟡 로그인 필요(살아 있음) · 🔴 응답 없음. 웹앱 코드(Code.gs) API 3이 필요해서 **2-B를 한 번 다시** 해야 켜집니다.
- 등록한 도구는 비공개 시트('tool' 분류)에만 저장되어 폰·PC에서 같게 보이고, 저장소(공개)에는 올라가지 않습니다.
- 아래 '이 앱 안의 도구'에서 기록·성장·퀘스트·내 자산 탭으로 바로 갈 수 있습니다.

## 문제가 생기면

| 화면 | 할 일 |
|---|---|
| 아직 집 PC가 화면 파일을 올리지 않았습니다 | 1번의 `--upload` 명령을 PC에서 실행. 웹앱을 다른 구글 계정에서 만들었다면 블로거 계정으로 다시 만들기 |
| 퀘스트 보드만 보이고 탭이 없음 | 웹앱 코드가 예전 것입니다 → 2-B |
| '죄송합니다. 지금은 파일을 열 수 없습니다' | 휴대폰 브라우저에 구글 계정이 여러 개 로그인돼 있을 때 생깁니다. 다른 계정에서 로그아웃하거나 그 계정만 로그인한 창에서 열기 |
| 자산 데이터를 불러오지 못했습니다 | 2-B를 했는지, 권한을 허용했는지 확인. 그래도 안 되면 그 문구를 Claude에게 알려 주세요 |
| 시세를 못 받은 종목: … | 종목코드를 확인하거나 그 종목은 '평가금액 직접 입력'을 쓰기 |
| 'N시간째 새 화면을 올리지 않았습니다'(퀘스트 보드) | 집 PC가 꺼져 있거나 절전 중. 켜지면 다음 정각 5분에 다시 올라옵니다 |
