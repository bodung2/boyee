# 인생 대시보드 웹앱 (휴대폰·밖에서 보기)

휴대폰이나 다른 컴퓨터에서 여는 **나만 볼 수 있는 웹앱**입니다. 위쪽 탭이 두 개입니다.

| 탭 | 내용 | 어디서 오나 |
|---|---|---|
| 퀘스트 보드 | 오늘 예약 작업 상태·최근 14일 발행 기록(보기 전용) | 집 PC가 매시간 드라이브에 올리는 `quest_board.html` |
| 내 자산 | 💰금융 · 💵파이프라인(부가수입) · 🏠부동산 · 👨‍👩‍👧사람 · ✍️저작물 · 🎖직위 · 🏆수상·자격 기록, 순자산 추이, 다가오는 생일·기념일, 인생 연표 | 이 구글 계정의 비공개 시트(웹앱이 처음 열릴 때 자동으로 만듦) |

```
집 PC (매시간 QuestBoardRefresh, 23:40 QuestBoard)
  └─ python -m quest_board --upload → 드라이브에 quest_board.html(보드)과 life_dashboard_app.html(화면)을 올림
구글 Apps Script 웹앱 (webapp/Code.gs, '나만' 접근)
  ├─ 화면: 드라이브의 life_dashboard_app.html
  ├─ 내 자산 데이터: 비공개 시트 '인생 자산 대시보드 (웹앱 데이터)' — 추가·수정·삭제는 화면에서
  ├─ 시세: 국내·미국 주식/ETF = 구글 파이낸스(약 20분 지연, 국내는 네이버 증권으로 보충), 코인 = 업비트 원화 시세
  └─ 매일 16시(한국 시간) 순자산을 기록 → 추이 그래프 (구글 서버에서 돌아 PC가 꺼져 있어도 됨)
```

- **나만 볼 수 있습니다.** 드라이브 파일·시트는 공유하지 않고, 웹앱도 '나만'으로 배포하므로 그 구글 계정으로 로그인해야 열립니다.
  GitHub 저장소는 공개라서 **코드와 화면만** 올라가고, 자산·가족 정보는 어디에도 올라가지 않습니다.
  (여러 블로그 주소가 한 화면에 모이는 퀘스트 보드도 같은 이유로 GitHub Pages에 올리지 않습니다.)
- 퀘스트 보드는 PC가 꺼져 있으면 마지막으로 올린 화면이 보이고, 2시간 반 넘게 새로 올라오지 않았으면 맨 위에 알려 줍니다.
  예약 조정 버튼(시각 바꾸기·끄기·지금 실행)은 집 PC의 `scripts\quest_board.bat` 화면에만 있습니다.

## 1. 집 PC: 드라이브에 올라가는지 확인 (1분)

구글 블로거 자동화를 쓰고 있다면 이미 드라이브 권한이 있습니다. PowerShell에서:

```powershell
cd $HOME\boyee
git pull
.venv\Scripts\python.exe -m quest_board --upload
```

`휴대폰 웹앱용 화면을 구글 드라이브에 올렸습니다`와 `인생 대시보드 화면(webapp/app.html)을 새로 올렸습니다`가 나오면 됩니다.
`구글 드라이브 권한이 없습니다`가 나오면 `.venv\Scripts\python.exe -m blogger_autopost auth`로 다시 로그인한 뒤 다시 실행하세요.
이후에는 매시간 예약 작업(QuestBoardRefresh)이 알아서 올립니다(예약 등록:
`powershell -ExecutionPolicy Bypass -File scripts\setup_all_schedules.ps1 -Only QuestBoard,QuestBoardRefresh -NoInstall`).

## 2-A. 웹앱 처음 만들기 (5분)

**블로거 자동화에 로그인한 그 구글 계정**으로 진행합니다(드라이브 파일이 그 계정에 있습니다).

1. 컴퓨터 브라우저에서 <https://script.google.com> → **새 프로젝트**. 이름을 `인생 대시보드`로 바꿉니다.
2. 편집기의 내용을 모두 지우고, 저장소의 [`webapp/Code.gs`](../webapp/Code.gs) 내용을 통째로 붙여 넣은 뒤 저장(Ctrl+S).
3. 오른쪽 위 **배포 → 새 배포** → 톱니바퀴(유형 선택) → **웹 앱**.
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **나만** ← 꼭 확인
4. **배포** → **액세스 승인** → 계정 선택. '확인되지 않은 앱'이 나오면 **고급 → (프로젝트 이름)(으)로 이동(안전하지 않음)** → **허용**.
   내가 만든 스크립트가 내 드라이브·시트를 읽고 쓰고, 시세 사이트에 접속하고, 매일 16시 기록 예약을 만들겠다는 뜻입니다.
5. 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 휴대폰에서 열고 **홈 화면에 추가**합니다.

## 2-B. 이미 만든 웹앱을 새 코드로 바꾸기 (주소는 그대로)

예전에 '퀘스트 보드' 웹앱을 만들었다면 새로 만들 필요 없이 코드만 바꿉니다. **휴대폰에 저장한 주소가 그대로 유지됩니다.**

1. <https://script.google.com>에서 그 프로젝트를 엽니다.
2. `Code.gs`의 내용을 모두 지우고 저장소의 [`webapp/Code.gs`](../webapp/Code.gs)를 붙여 넣은 뒤 저장.
3. **배포 → 배포 관리** → 지금 배포 옆 **연필(수정)** → 버전: **새 버전** → **배포**.
   ('새 배포'를 누르면 주소가 바뀌니 '배포 관리'에서 고치세요.)
4. 권한을 새로 묻습니다(시트·시세 사이트·예약). 2-A의 4번처럼 허용합니다.

**코드를 다시 붙여 넣어야 하는 때:** 화면(탭·카드·그래프)만 바뀐 업데이트는 PC가 화면 파일을 다시 올리므로 할 일이 없습니다.
`webapp/Code.gs`가 바뀐 업데이트일 때만 2-B를 다시 하면 되고, 그때는 웹앱 화면 맨 위에 '웹앱 코드가 예전 버전입니다'라고 알려 줍니다.

## 3. 내 자산 쓰는 법

- 오른쪽 아래 **＋ 추가** → 분류를 고르고 적습니다. 카드를 누르면 수정·삭제할 수 있습니다.
- **금융:** 국내 주식·ETF(6자리 코드), 미국 주식·ETF(티커, 평단가는 달러), 코인(BTC 같은 기호)은 수량·평단가만 적으면 시세로 평가하고
  수익률을 보여 줍니다. 예적금·현금·연금·기타는 금액을 직접 적습니다(바뀌면 고쳐 주세요). 시세를 못 받는 종목은 '평가금액 직접 입력'을 쓰세요.
- **파이프라인(부가수입 통로):** 종류(광고·제휴·인세·강의·외주·콘텐츠 판매·배당·임대 등)·상태(운영 중·준비 중·쉬는 중·접음)·월 수입.
  '운영 중'인 것의 월 합계와 연 환산을 보여 줍니다. 순자산에는 더하지 않습니다.
- **부동산:** 매입가·현재 시세·대출 잔액. 시세는 자동이 아니라 가끔 직접 고칩니다.
- **사람:** 이름·관계·생일(양력)·기념일. 요약 화면에 60일 안의 생일·기념일이 D-day로 나옵니다.
- **저작물·직위·수상:** 날짜와 함께 남기면 '📜 연표'에 연도별로 모입니다. 직위는 종료일을 비워 두면 '지금 맡고 있는 일'로 보입니다.
- **순자산**(금융 + 부동산 − 대출)은 매일 16시에 기록되고, 이틀 이상 쌓이면 추이 그래프(1개월·3개월·1년·전체)가 나옵니다.
  화면을 열 때 시세가 30분 넘게 지났으면 알아서 새로 받고, '시세 새로고침'으로 바로 받을 수도 있습니다.
- **링크(선택):** 모든 분류에 링크 칸이 있습니다(블로그 관리 화면, 계좌, 문서, 증빙 등). 카드의 '링크'를 누르면 바로 열립니다.
- 데이터는 요약 화면 맨 아래 **시트 열기**로 원본 시트를 볼 수 있습니다(백업·엑셀로 내려받기). 시트의 열 이름·순서는 바꾸지 마세요.

## 4. 🏅 성장 탭 (6대 목표 점수)

신체 · 정신 · 기능·영감 · 사회 · 커리어 · 경제 기록을 **30대 후반 남성 중 상위 몇 %**인지로 바꿔, 모든 영역을 같은 공식으로 점수화합니다.

- **점수 = 10 × log₂(0.5 ÷ 상위 비율)**: 평균(상위 50%) 0점 · 상위 25% 10점 · 10% 23점 · 1% 56점. 기록만 해도 주 1점.
- **흐름 점수(매주):** 운동 횟수, 가사·돌봄 시간(요리·놀이·정리·설거지·청소·분리수거), 교류·나눔 시간, 정신 성취, 커리어 성취, 월 저축률(주 단위로 환산).
  한 영역 한 주 최대 56점(상위 1%)으로 모든 영역이 같습니다.
- **돌파 점수(한 번):** 순자산 구간, 파이프라인 월수입 구간, 직업(취직·전직·승진)·수상·자격·저작물(희소도별), 대회 완주, 체력 등급, 누적 봉사, 숙련 단계, 스트레스 점검 상위 구간. 같은 희소도의 4배.
- **과거의 성취도 나:** '오늘부터 시작하기'를 누른 날 이전 업적도 줄이지 않고 같은 점수로 들어갑니다('과거 업적' 표시만 붙음). 누적 점수는 줄지 않습니다.
- **커리어:** 결과만 기록합니다. 종류(업무 성과·본업 전문성·사람을 키운 성과·리더십·혁신·대외 활동)와 크기를 골라 정신과 같은 규칙으로 점수.
  '상위 %'는 지금 하고 있는 일의 직업 상위 %(아래 '직업 돌파'와 같은 계산). 학습 시간은 점수에 넣지 않습니다.
- **직업 돌파(취직·전직·승진):** 내 자산 → 직위 카드에 직업군·직위 수준·고용 형태·연봉을 적으면 그 일의 상위 %를 세 지표의 평균으로 냅니다.
  ① 지위 — 직업대분류 취업자 구성비(지역별고용조사 2026 상반기)를 '월 500만 원 이상 비율' 순으로 세우고, 직업군 안에서는 직위 수준(교원 직위 비율)으로 위치를 정함
  ② 연봉 — 같은 조사의 월 임금 분포를 30대 남자 평균 보수로 올린 분포(중앙 연 약 4,120만 원)
  ③ 안정성 — 공공부문 10% · 민간 정규직 37.5% · 자영업 등 22.7% · 비정규직 29.7% 순.
  날짜순으로 보며 '지금까지 가장 높은 직업'보다 오른 만큼만 돌파 점수가 더해집니다(같은 급 이직을 되풀이해도 늘지 않음).
  예: 교사(전문가 · 공공 · 연 5,800만) ≈ 상위 16% → 돌파 약 66점. 교사는 교감·교장이 되어도 직업군은 '전문가'로 두고 직위 수준만 바꿉니다.
- **두 갈래 점수:** 📈 흐름 점수(매일·매주 기록이 쌓인 것) + 🏆 돌파 점수(업적을 이룬 것). 성장 탭 맨 위에 따로 보이고, '최근 얻은 점수'에도 표시됩니다.
- **파이프라인 수익 기록:** 내 자산 → 파이프라인 카드를 열면 '💰 수익 기록'에 들어온 날과 금액을 적습니다.
  파이프라인마다 누적 수익이 1만·10만·100만·1,000만·1억 원을 넘는 날 돌파 점수가 생깁니다(시작일 이전 수익도 같은 점수).
- **자산 탭도 점수에 들어갑니다(돌파):** 직위·수상·자격·저작물(발표·수익), 순자산 구간, 파이프라인 월수입 합계 구간·누적 수익 구간,
  첫 내 집 마련(30대 주택 소유율 36%), 결혼·자녀(태어난 순서). 항목의 날짜가 점수 시작일
  이전이거나 비어 있으면 '과거 업적'으로 표시되지만 점수는 똑같습니다.
- **정신:** 영역(규율·감정·충동·회피·마음)과 크기(작은 승리 5 · 의미 있는 승리 15 · 큰 돌파 40, 월 1회)를 골라 기록.
  같은 주 같은 영역 반복은 절반 → 0. '상위 %'는 월 1회 스트레스 점검(PSS-10, 10문항)으로 냅니다.
- **정직한 기록:** 날짜는 오늘·어제만 고를 수 있습니다.
- **화면:** 쌓은 점수 육각형 + 상위 % 육각형, 주간·월간·누적 성적표, 최근 얻은 점수.
  누적은 시작일부터의 평균 페이스(운동 주당 횟수, 시간 하루 평균, 저축률·스트레스 점검 평균)에 지금까지 이룬 상태 지표를 더해 영역마다 평균합니다.
  신체(체력 등급·대회 완주) · 기능(숙련 단계) · 사회(결혼·자녀·누적 봉사) · 커리어(지금 하는 일·수상·자격·저작물) · 경제(순자산·내 집·파이프라인 월수입).
  적어 둔 지표만 평균하고, 각 줄 아래에 쓰인 지표와 상위 %가 보입니다.
  매주 처음 열 때 그 주의 누적 상위 %를 시트에 기록('누적 상위 % 기록(매주)' 표)하고, 지난 기록보다 좋아지면 ▲, 나빠지면 ▼로 보여 줍니다.
  **점수 기준·출처 보기**에 모든 기준 숫자와 출처, 근거 수준(공식 / 평균 공식·분포 추정 / 추정 / 해외 규준)이 나옵니다.
- 직위 카드에는 '직업군'·'직위 수준'·'고용 형태'·'연봉', 수상 카드에는 '수상 수준'·'자격 난이도' 칸이 있어 돌파 점수의 희소도를 정합니다.

## 문제가 생기면

| 화면 | 할 일 |
|---|---|
| 아직 집 PC가 화면 파일을 올리지 않았습니다 | 1번의 `--upload` 명령을 PC에서 실행. 웹앱을 다른 구글 계정에서 만들었다면 블로거 계정으로 다시 만들기 |
