# 퀘스트 보드 웹앱 (휴대폰·밖에서 보기)

집 PC의 퀘스트 보드(오늘 예약 작업 상태·최근 14일 발행 기록)를 **휴대폰이나 다른 컴퓨터에서 보기 전용으로** 엽니다.

```
집 PC (매시간 QuestBoardRefresh, 23:40 QuestBoard)
  └─ python -m quest_board --upload → 구글 드라이브의 quest_board.html(나만 볼 수 있음)을 덮어씀
휴대폰 브라우저
  └─ 구글 Apps Script 웹앱('나만' 접근) → 드라이브의 quest_board.html을 그대로 보여 줌
```

- **나만 볼 수 있습니다.** 드라이브 파일은 공유하지 않고, 웹앱도 '나만'으로 배포하므로 그 구글 계정으로 로그인해야 열립니다.
  GitHub 저장소는 공개라서 GitHub Pages(시장 대시보드 주소)에는 올리지 않습니다. 여러 블로그 주소가 한 화면에 모이면
  블로그끼리(예: 투자 블로그와 교사 블로그) 같은 사람이라는 게 드러날 수 있기 때문입니다.
- **PC가 꺼져 있어도 열립니다.** 마지막으로 올린 화면이 보이고, 2시간 반 넘게 새로 올라오지 않았으면 맨 위에 알려 줍니다.
- 보기 전용입니다. 시각 바꾸기·끄기·지금 실행 버튼은 집 PC의 `scripts\quest_board.bat` 화면에만 있습니다.

## 1. 집 PC: 드라이브에 올라가는지 확인 (1분)

구글 블로거 자동화를 쓰고 있다면 이미 드라이브 권한이 있습니다. PowerShell에서:

```powershell
cd $HOME\boyee
git pull
.venv\Scripts\python.exe -m quest_board --upload
```

`휴대폰 웹앱용 화면을 구글 드라이브에 올렸습니다`가 나오면 됩니다.
`구글 드라이브 권한이 없습니다`가 나오면 `.venv\Scripts\python.exe -m blogger_autopost auth`로 다시 로그인한 뒤 위 명령을 다시 실행하세요.
이후에는 매시간 예약 작업(QuestBoardRefresh)이 알아서 올립니다(예약 등록:
`powershell -ExecutionPolicy Bypass -File scripts\setup_all_schedules.ps1 -Only QuestBoard,QuestBoardRefresh -NoInstall`).

## 2. 웹앱 만들기 (최초 1회, 5분)

**블로거 자동화에 로그인한 그 구글 계정**으로 진행합니다(드라이브 파일이 그 계정에 있습니다).

1. 컴퓨터 브라우저에서 <https://script.google.com> → **새 프로젝트**.
2. 왼쪽 위 '제목 없는 프로젝트'를 눌러 이름을 `퀘스트 보드`로 바꿉니다.
3. 편집기에 있는 내용을 모두 지우고, 저장소의 [`docs/quest_board_webapp.gs`](quest_board_webapp.gs) 내용을 통째로 붙여 넣은 뒤 저장(Ctrl+S).
4. 오른쪽 위 **배포 → 새 배포** → 톱니바퀴(유형 선택) → **웹 앱**.
   - 설명: `퀘스트 보드`
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **나만** ← 꼭 확인
5. **배포** → **액세스 승인** → 계정 선택.
   '확인되지 않은 앱' 화면이 나오면 **고급 → 퀘스트 보드(으)로 이동(안전하지 않음)** → **허용**.
   (내가 만든 스크립트가 내 드라이브를 읽겠다는 뜻입니다. 다른 사람은 이 스크립트를 쓸 수 없습니다.)
6. 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다.

## 3. 휴대폰에 붙이기

1. 그 URL을 휴대폰으로 보냅니다(나에게 카톡·메일 등). 남에게 보내도 그 사람은 열 수 없지만, 굳이 공유하지 마세요.
2. 휴대폰 브라우저(크롬·사파리)에서 열고, 같은 구글 계정으로 로그인합니다.
3. **홈 화면에 추가**(크롬: ⋮ → 홈 화면에 추가 / 사파리: 공유 → 홈 화면에 추가)하면 앱처럼 열 수 있습니다.

## 문제가 생기면

| 화면 | 할 일 |
|---|---|
| 아직 집 PC가 퀘스트 보드를 올리지 않았습니다 | 1번의 `--upload` 명령을 PC에서 실행. 웹앱을 다른 구글 계정에서 만들었다면 블로거 계정으로 다시 만들기 |
| '죄송합니다. 지금은 파일을 열 수 없습니다' | 휴대폰 브라우저에 구글 계정이 여러 개 로그인돼 있을 때 생깁니다. 다른 계정에서 로그아웃하거나 시크릿 창에서 그 계정으로만 로그인 |
| 'N시간째 새 화면을 올리지 않았습니다' | 집 PC가 꺼져 있거나 절전 중. 켜지면 다음 정각 5분에 다시 올라옵니다 |
| 텔레그램 요약에 '휴대폰 웹앱 화면을 올리지 못했습니다' | 그 뒤에 적힌 이유대로(대개 `python -m blogger_autopost auth` 다시 로그인) |

웹앱 코드(`docs/quest_board_webapp.gs`)는 바뀔 일이 거의 없습니다. 화면 모양이 바뀌어도 PC가 올리는 파일만 바뀌므로 다시 배포할 필요가 없습니다.
