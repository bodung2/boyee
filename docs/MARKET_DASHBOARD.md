# 자산군 모멘텀 대시보드

주식·채권·실물·통화·비트코인 등 19개 자산군의 추세를 한 화면에 놓고, 미리 정한 규칙대로 "지금 무엇을 얼마나 담을지"를 계산합니다. 같은 규칙을 2006년부터 원화 기준으로 돌린 백테스트도 함께 보여 줍니다.

> 참고 자료이며 매매 신호가 아닙니다. 과거 성과가 미래 수익을 보장하지 않습니다.

## 웹 주소 (매일 자동 갱신)

**https://bodung2.github.io/boyee/**

GitHub Actions(`.github/workflows/market-dashboard.yml`)가 한국 시간 화~토 07:30(전날 미국장 마감 반영)에 새로 계산해 GitHub Pages에 올립니다. PC가 꺼져 있어도 됩니다. 주소를 아는 사람은 누구나 볼 수 있습니다(시장 데이터와 규칙만 있고 개인 정보는 없음).

최초 1회 설정:
1. 저장소 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 바꿉니다.
2. (선택) 텔레그램 요약: **Settings → Secrets and variables → Actions → New repository secret**에 `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`를 넣습니다(.env와 같은 값).
3. **Actions → market-dashboard → Run workflow**로 한 번 실행하면 몇 분 뒤 주소가 열립니다.

Yahoo 접속이 막힌 날은 지난번에 받아 둔 시세(Actions 캐시)로 화면을 만들고, 그것도 없으면 그날 실행만 실패하고 어제 화면이 그대로 남습니다.

## PC에서 실행 (선택)

```powershell
powershell -ExecutionPolicy Bypass -File scripts\setup_market_windows.ps1 -Time 07:40   # 최초 1회: 패키지 설치 + 화~토 07:40 예약 + 지금 한 번 실행
.venv\Scripts\python.exe -m market_dashboard run            # 수동 실행 → output\market\dashboard.html
.venv\Scripts\python.exe -m market_dashboard run --notify   # + 텔레그램으로 오늘의 답(.env의 TELEGRAM_BOT_TOKEN·CHAT_ID)
.venv\Scripts\python.exe -m market_dashboard run --offline  # 받아 둔 데이터(data\market\)로만 다시 계산
```

데이터는 yfinance(배당·이자 재투자 반영 수정주가)와 FRED(연준 유동성·금리·스프레드)에서 받습니다. API 키는 필요 없습니다.

## 화면

| 영역 | 내용 |
|---|---|
| 사분면 | 가로 = 추세 강도(0 = 현금과 같음), 세로 = 가속도. 주도(매수 후보) → 둔화 → 회피 → 회복 순으로 시계방향으로 돈다. **시간 막대**(▶ 재생·1×/2×/4× 속도, ◀▶ 1주씩, 키보드 ←→, 막대 끌기)로 최근 1년을 거래일 단위로 되돌려 본다. 날짜 사이를 보간해 점이 끊기지 않고 움직이며, 최근 1주 사이 사분면이 바뀐 자산이 위에 표시된다. 꼬리 = 그 시점까지 8주(오래될수록 흐림), 점 크기 = 그 시점 규칙상 비중(노란 테두리 = 보유), 점을 누르면 52주 상관 선(굵기 = 크기, 주황 = 같이, 보라 = 반대, 점선 = 3년 평균과 0.4 이상 달라짐) |
| 오늘의 답 | 강한 순 표. 규칙상 목표 비중, 탈락 사유(상관 겹침·순위 밖·확인 부족) |
| 시장 체온 | 유동성 온도(연준 순유동성·하이일드 스프레드·실질금리·달러의 13주 변화 z 평균), 경기 국면(구리/금 × 기대인플레이션), 평균 상관계수 |
| 백테스트 | 원화 기준 누적 가치·낙폭, S&P500 보유·60/40·올웨더와 비교, 규칙 변형(과적합 점검), 연도별 수익, 보유 이력 |

## 색

검은 바탕에 흰 글씨. 노랑 = 규칙상 편입·주목, 빨강 = 상승(+), 파랑 = 하락(−) — 한국 시세 표기 관례.

## 규칙 (`market_dashboard/signals.py`의 `Params`)

1. 추세 강도 = 3·6·12개월 "현금(미 3개월 국채금리 ^IRX를 쌓은 지수) 대비 초과 로그수익 ÷ (일간 변동성 × √기간)"의 평균. 최근 10거래일은 뺀다. 신호는 달러 기준 가격으로 계산한다.
2. 가속도 = 지금 추세 강도 − 20거래일 전 추세 강도.
3. 편입 조건: 추세 강도 > 0, 3개 기간 중 2개 이상 현금보다 우위, 200일선 위.
4. 강한 순으로 최대 5개. 이미 보유한 자산은 7위까지 밀려도 유지. 이미 담은 자산과 52주(주간 수익률) 상관이 0.7을 넘으면 건너뜀.
5. 비중 = 63일 변동성 역가중, 한 자산 최대 35%, 남는 비중은 현금(달러 단기국채로 계산하므로 원화로는 환율 영향을 받음).
6. 과열(🔥): 50일선 이탈이 변동성 대비 2.5배 이상 → 분할 매수 표시(백테스트에는 반영하지 않음).
7. 월말 종가 신호 → 다음 거래일 종가 체결, 편도 비용 0.15%(거래+환전 가정).

## 백테스트에서 빠진 것

- 세금: 해외 직투 양도차익 22%(연 250만 원 공제), 국내 상장 해외 ETF 매매차익 15.4%(금융소득종합과세 대상 가능).
- 실제 체결 가격 차이, 환전 우대율 차이.
- 백테스트는 비교 대상(올웨더의 원자재 DBC, 2006년 2월 상장)이 모두 있는 날부터 같은 기간으로 비교한다.
- 상장 전 자산(비트코인 2014~, 구리 ETF 2011~, 한국 국고채 10년 ETF 2011~)은 12개월 데이터가 쌓인 뒤부터 후보에 들어간다.
