# 아이와 가볼 곳 (유아 블로그, 직접 찍은 사진 글)

아이들과 직접 다녀온 장소를 **내가 찍은 사진 + 짧은 메모**로 소개하는 글을 자동으로 올립니다.
AI가 지어낸 경험이 하나도 없어서 사람 냄새가 나는 글이 됩니다. 경험은 메모에 적은 것만 쓰고,
운영시간·요금·주차 같은 정보만 공식 홈페이지로 확인합니다.

```
places_inbox\국립과천과학관\  (사진 3장 이상 + 메모.txt)
   ↓  매일 18:10 예약 작업(NaverAutoPost-place) — 새 폴더가 없으면 아무것도 안 하고 끝남
사진 준비: 위치 정보(GPS) 삭제 · 얼굴 자동 흐림 · 크기 줄이기 · 촬영 순서로 정리
   ↓
글쓰기(childhood-place-post): 메모 말투·아이가 한 말 그대로, 동선 순서, 아쉬운 점도 솔직하게, 교사 눈으로 본 한 문단
   ↓
검수(childhood-place-factcheck): 장소 정보 대조 · 메모에 없는 경험 삭제 · 사진을 직접 보고 얼굴·명찰·번호판 걸러냄
   ↓
ChatGPT 교차검증(장소 정보만) → 유아 블로그 '아이와 가볼 곳' 카테고리에 발행 → 폴더를 _발행됨으로 옮김 → 텔레그램 알림
```

## 처음 한 번 (집 PC)

1. **블로그에 카테고리 만들기:** 네이버 블로그 관리 → 메뉴·글·동영상 관리 → 블로그 → 카테고리 추가 → 이름 `아이와 가볼 곳`.
   (다른 이름을 쓰려면 `.env`에 `NAVER_CATEGORY_PLACE=원하는 이름`. 카테고리가 없으면 기본 카테고리로 올라가고 알림에 ⚠️가 붙습니다.)
2. **예약 작업 등록:** PowerShell에서
   ```powershell
   cd $HOME\boyee
   powershell -ExecutionPolicy Bypass -File scripts\setup_all_schedules.ps1 -Only NaverAutoPost-place -NoInstall
   ```
   필요한 프로그램(얼굴 흐림용 OpenCV, 아이폰 HEIC 사진용 pillow-heif)은 다음 예약 작업 때 자동으로 설치됩니다.
3. 로그인은 유아 블로그와 같은 것을 씁니다(따로 로그인할 필요 없음).

## 장소 하나 올리기

1. `boyee\places_inbox\` 안에 장소 이름으로 폴더를 만듭니다(처음 실행 때 `places_inbox`와 `_메모_예시.txt`가 생깁니다).
2. 그 폴더에 **사진 3장 이상**과 **메모.txt**를 넣습니다.
3. 끝. 그날 18:10에 올라가고 텔레그램으로 알려 줍니다. 폴더는 `places_inbox\_발행됨\날짜 장소이름`으로 옮겨집니다.

- 하루에 한 곳씩, 먼저 넣은 폴더부터 올립니다. 여러 곳을 한꺼번에 넣어 두면 하루 한 편씩 나갑니다.
- 사진을 넣고 10분이 지나야 씁니다(복사 중인 폴더를 건드리지 않게).
- 메모가 없거나 너무 짧거나 사진이 모자라면 그날은 올리지 않고 무엇이 빠졌는지 알려 줍니다.

### 메모.txt 예시

형식은 자유입니다. 짧은 말투 그대로 적어도 됩니다. **아이가 한 말, 아쉬웠던 점, 우리만 아는 꿀팁**이 많을수록 사람 냄새가 납니다.

```
장소: 국립과천과학관
다녀온 날: 2026-10-18(토), 오전 10시~오후 2시
누구와: 첫째(6살), 둘째(4살)
제일 좋아한 것: 첫째는 천체투영관, 둘째는 유아체험관 물놀이 코너. 둘째가 나오기 싫다고 울었음
아이가 한 말: "아빠 별이 진짜 머리 위로 지나가!"
아쉬웠던 점: 주말 11시쯤 유아체험관 대기 40분. 식당 줄도 김
꿀팁: 유아체험관은 홈페이지 회차 예약 먼저. 여벌 옷 꼭. 주차장은 10시 전에 가야 여유
한 줄 평: 4~7살이면 반나절 코스로 딱. 재방문 의사 있음
```

적지 말 것: 아이 이름, 어린이집·학교 이름, 사는 동네(메모에 있어도 글에는 '첫째·둘째'로만 씁니다).
메모장에서 저장할 때 인코딩은 상관없습니다(UTF-8·ANSI 모두 읽습니다).

## 아이 사진 보호

- **위치 정보:** 사진 속 GPS·촬영 기기 정보는 올리기 전에 모두 지웁니다(원본 파일은 그대로 둡니다).
- **얼굴:** 두 가지 방법(OpenCV YuNet 모델 + 옛 방식 Haar)으로 얼굴을 찾아 하나라도 찾으면 흐립니다.
  YuNet 모델은 처음 한 번 인터넷에서 받아 `data\models`에 둡니다(받지 못하면 옛 방식만 씁니다).
  얼굴 찾기를 아예 쓸 수 없으면 사진을 올리지 않고 멈춥니다.
- **검수가 사진을 직접 봅니다:** 흐림이 빠진 얼굴, 명찰·이름표, 어린이집 로고, 읽히는 차 번호판, 집 주소가 보이는 사진은 글에서 뺍니다.
  빼고 나서 사진이 2장 미만이면 그날은 올리지 않고 알려 줍니다.
- 그래도 완벽하지는 않습니다. 아이 얼굴이 크게 나온 사진보다 **뒷모습·손·풍경·시설 사진**을 넣는 것이 가장 안전합니다.
- `places_inbox`와 `data\models`는 GitHub에 올라가지 않습니다(.gitignore).

## 문제가 생기면

| 상황 | 할 일 |
|---|---|
| 퀘스트 보드에 '건너뜀' | 그날 새 폴더가 없었다는 뜻. 정상입니다 |
| 텔레그램 "장소 폴더를 확인해 주세요" | 적힌 대로 메모·사진을 채우면 다음 날 18:10에 올라갑니다 |
| "사진이 N장만 남아 올리지 않았습니다" | 얼굴·명찰이 보이는 사진이 빠진 것. 뒷모습·풍경 사진을 더 넣기 |
| "OpenCV가 설치되지 않아" | `.venv\Scripts\python.exe -m pip install -r requirements.txt` |
| 지금 바로 올리고 싶을 때 | `scripts\run_daily.bat --profile place` |
| 글 규칙을 바꾸고 싶을 때 | `.claude/skills/childhood-place-post/SKILL.md`(쓰기), `childhood-place-factcheck/SKILL.md`(검수) |

참고: 이 글은 인스타·쓰레드로 자동 재가공하지 않습니다(아이 사진이 SNS로 더 퍼지지 않게).
