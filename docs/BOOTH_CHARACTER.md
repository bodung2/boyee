# 캐릭터 공방 (부스 활동)

아이가 **종이 학습지에 그린 캐릭터**를 폰으로 찍어 보내면, **집 PC**가 ChatGPT로 고른 모습(양모펠트·2D 애니메이션 등)으로 바꿔
아이 폰에 보여 줍니다. 아이는 완성 그림을 **패들렛에 직접 올리고**, 부스에서는 선생님이 패들렛을 보며 **셀피로 인쇄**합니다.
그림은 블로그 일러스트와 같은 방식(**Codex CLI + ChatGPT 구독**)이라 **API 결제가 없습니다**. 부스에 노트북이 없어도 됩니다.

```
아이 폰  ── QR ──▶  웹앱(구글 Apps Script, 로그인 없이 열림)
                     ① 별명  ② 학습지 그림 찍기  ③ 모습 고르기(8가지)  ④ 소개(취미·특기, 선택)  → 보내기
                     └─ 드라이브 '원본' 폴더(비공개) + 대기열 시트에 한 줄
집 PC (행사 시간 동안 scripts\run_booth.bat 켜 두기)
  3초마다 대기열 확인 → ChatGPT(Codex)가 학습지 사진을 참고해 새로 그림(1~2분) → 결과를 드라이브 '결과' 폴더에 올림
아이 폰  완성 그림이 뜸 → 꾹 눌러 저장 → [📌 패들렛에 올리기] → 별명을 제목으로 게시
부스     선생님 폰·태블릿으로 패들렛을 보며 그림 저장 → 셀피 앱으로 인쇄
큰 화면  (선택) 웹앱 주소 뒤에 ?view=wall → 완성 그림이 15초마다 모여 보임
```

**고를 수 있는 모습 8가지:** 🧶 양모펠트 인형 · 🟠 클레이 인형 · 📺 2D 애니메이션 · 🎬 3D 애니메이션 · 🧸 봉제 인형 · 🎮 픽셀아트 게임 · 🎨 수채화 그림책 · 🌟 스티커
(특정 회사·작품 이름은 쓰지 않고 재료·기법으로만 설명합니다. 바꾸려면 `booth/styles.py`, `booth/apps_script/Code.gs`, `index.html` 세 곳을 같이.)

---

## 0. 준비물

- **집 PC**(블로그 자동화를 돌리는 그 컴퓨터 — Codex가 이미 로그인돼 있어 따로 설치할 것이 없습니다)
- **개인 구글 계정**(@gmail.com 권장 — 학교 구글 계정은 '모든 사용자' 공개·링크 공유가 막혀 있을 수 있습니다)
- **패들렛 보드** 하나(학교 계정으로 만들어도 됩니다)
- 부스: **셀피 CP1500** + 엽서 용지·잉크 세트(KP-108IN 등), 인쇄할 **선생님 폰이나 태블릿**

## 1. 웹앱 만들기 (10분)

1. 개인 구글 계정으로 <https://script.google.com> → **새 프로젝트**, 이름 `캐릭터 공방`.
2. `Code.gs` 내용을 모두 지우고 저장소의 [`booth/apps_script/Code.gs`](../booth/apps_script/Code.gs)를 붙여 넣기.
3. 왼쪽 **파일 +** → **HTML** → 이름을 `index`로(뒤에 .html은 자동). 내용을 지우고
   [`booth/apps_script/index.html`](../booth/apps_script/index.html)을 붙여 넣기. 저장(Ctrl+S).
4. 위쪽 함수 목록에서 **setupBooth** 선택 → **▶ 실행** → 권한 승인('확인되지 않은 앱'이면 고급 → 이동 → 허용).
   아래 **실행 로그**에 `BOOTH_TOKEN=…` 줄이 나옵니다. 드라이브에 `캐릭터 공방 (부스)` 폴더와 대기열 시트가 생깁니다.
5. **배포 → 새 배포 → 웹 앱**
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자** ← 아이들이 로그인 없이 열어야 해서
6. 나온 **웹 앱 URL**(`…/exec`)을 적어 둡니다.

> 나중에 코드가 바뀌면: 두 파일을 다시 붙여 넣고 **배포 → 배포 관리 → 연필 → 새 버전 → 배포**(주소는 그대로).

## 2. 패들렛 보드 준비 (5분)

1. 부스용 보드를 만듭니다(서식: 담벼락·그리드 추천).
2. **공유** → 링크가 있는 사람의 권한을 **작성 가능**으로 → 아이들이 로그인 없이 올릴 수 있습니다.
   (학교 계정에서 '학교 사람만'으로 막혀 있으면 아이 폰에서 로그인을 요구합니다 — 링크 공개로 바꿔 주세요.)
3. **설정 → 게시물 승인 필요**를 켜 두면 선생님이 확인한 뒤에 보입니다(권장).
4. 보드 주소(`https://padlet.com/…`)를 복사해 둡니다.

## 3. 집 PC 설정 (5분)

PR이 병합된 뒤 집 PC는 다음 예약 작업 때 새 코드를 자동으로 받습니다(바로 하려면 PowerShell에서 `cd $HOME\boyee` → `git pull`).
`.env`에 아래를 적습니다(`.env.example` 맨 아래 참고).

```
BOOTH_WEBAPP_URL=https://script.google.com/macros/s/…/exec
BOOTH_TOKEN=(1단계 실행 로그의 값)
PADLET_BOARD=https://padlet.com/…/보드이름-abc123xyz
```

`BOOTH_PRINTER`는 **비워 둡니다**(집 프린터로 인쇄하지 않음). 확인:

```powershell
.venv\Scripts\python.exe -m booth check
```

웹앱 연결·Codex·패들렛이 ✅면 됩니다. 이때 집 PC가 웹앱에 패들렛 주소를 알려 줘서 아이 폰 완성 화면에 **📌 패들렛에 올리기** 버튼이 생깁니다.

## 4. 셀피 인쇄 준비 (부스, 10분)

1. 선생님 폰·태블릿에 캐논 **SELPHY Photo Layout** 앱을 설치하고, 앱 안내대로 셀피 CP1500과 와이파이로 연결합니다.
2. 엽서 용지·잉크를 넣고 사진 한 장을 시험 인쇄합니다.
3. 부스에서는: 패들렛(또는 큰 화면 갤러리)에서 아이 그림을 열어 **저장** → 앱에서 그 사진 골라 **인쇄**(한 장 약 40초).

## 5. 리허설 (꼭!)

집 PC에서:

```powershell
scripts\run_booth.bat --fake
```

`--fake`는 ChatGPT를 쓰지 않고 색만 바꾼 그림을 만들어 **폰 → 완성 화면 → 패들렛 올리기 → 셀피 인쇄** 흐름만 연습합니다(구독 사용량 안 씀).
폰으로 웹앱 주소(또는 QR)를 열어 학습지를 찍어 보내 보세요.
그다음 `scripts\run_booth.bat`(진짜)로 **10장쯤 연달아** 보내 보며 한 장에 걸리는 시간과 ChatGPT 사용 한도를 확인합니다.

QR 안내판 만들기:

```powershell
.venv\Scripts\python.exe -m booth qr
```

`output\booth\qr_안내판.png`(A4)를 인쇄해 부스에 붙입니다. 함께 나오는 **큰 화면 주소**는 TV가 있으면 띄웁니다.

## 6. 당일 운영

**집을 나서기 전(집 PC):**
- `scripts\run_booth.bat` 더블클릭 → 설정 점검(✅/❌) 뒤 바로 시작합니다. **창을 끄지 마세요.**
- 윈도우 전원 설정을 **절전 안 함**으로(잠들면 변환이 멈춥니다).
- 블로그 예약 작업도 같은 ChatGPT 구독을 씁니다. 행사 시간과 겹치는 작업이 있으면 퀘스트 보드(`scripts\quest_board.bat`)에서
  그날만 꺼 두면 한도에 덜 걸립니다.
- (권장) 크롬 원격 데스크톱을 깔아 두면 밖에서 폰으로 집 PC 창을 보고 다시 켤 수 있습니다.

**부스에서:**
- 한 장에 1~2분. 아이 폰에는 '앞에 N명' → '그리는 중' → 완성 그림이 차례로 뜹니다. 화면을 켜 두라고 안내해 주세요.
- 아이가 그림을 저장해 패들렛에 올리면, 선생님이 승인하고 저장 → 셀피로 인쇄.
- 줄이 길면 집 PC `.env`에 `BOOTH_PARALLEL=2`(동시에 2장)로 바꾸고 다시 켭니다. 대신 ChatGPT 한도에 더 빨리 닿을 수 있습니다.
- **다시 그리기:** 대기열 시트에서 그 줄의 '상태'를 `대기`로 바꾸면 집 PC가 다시 가져갑니다.
- 그림이 아닌 사진(얼굴 등)을 보내면 AI가 그리지 않고, 아이 폰에 '캐릭터 그림만 다시 찍어 주세요'가 뜹니다.
- 완성 그림은 아이가 저장하지 않아도 드라이브 `캐릭터 공방 (부스)/결과` 폴더와 집 PC `output\booth\날짜\`에 모두 남습니다.

## 문제 해결

| 화면·창의 메시지 | 원인 | 할 일 |
|---|---|---|
| 아이 폰이 '부스 컴퓨터가 준비되면…'에서 멈춤 | 집 PC 창이 꺼짐·잠듦·인터넷 끊김 | 원격으로 `run_booth.bat` 다시 실행(받은 그림은 순서대로 처리) |
| ⏸ ChatGPT 로그인·사용 한도 문제로 1분 쉽니다 | 로그인 풀림·구독 한도 | 집 PC에서 `codex` 실행해 로그인 확인. 그림은 대기열에 그대로 있어 자동으로 이어집니다 |
| ❌ 웹앱 연결 — 토큰이 맞지 않습니다 | `.env` 토큰이 다름 | 편집기에서 setupBooth 다시 실행 → 로그의 토큰으로 |
| ❌ 웹앱 연결 — JSON이 아닌 답 | 배포 액세스가 '나만' | 배포 관리 → 액세스 **모든 사용자** → 새 버전 |
| 완성 화면에 '패들렛에 올리기' 버튼이 없음 | `PADLET_BOARD`가 비었거나 집 PC가 아직 안 켜짐 | `.env` 확인 후 `run_booth.bat` 다시 실행 |
| 아이 폰에서 패들렛이 로그인을 요구 | 보드가 학교 사람만 쓰기 | 보드 공유 → 링크가 있는 사람 **작성 가능** |
| '크게 보기·저장' 버튼이 없음 | 구글 계정이 링크 공유를 막음(학교 계정 등) | 그림을 꾹 눌러 저장하면 됩니다. 버튼이 필요하면 개인 @gmail.com 계정으로 웹앱을 만들기 |

## (선택) 패들렛 자동 게시

패들렛 **설정 → 개발자(Developer)**에서 API 키를 만들 수 있으면 `.env`에 `PADLET_API_KEY=키`를 넣습니다.
그러면 아이가 올리지 않아도 집 PC가 `별명의 캐릭터 · 모습` 제목으로 자동 게시하고, 아이 화면의 패들렛 버튼은 숨겨집니다(두 번 올라가지 않게).
확인: `.venv\Scripts\python.exe -m booth padlet-test`. 패들렛은 공개 API 키를 개인 유료 요금제(Neon·Platinum)에만 주고 단체(학교) 계정은
아직 막혀 있다고 안내하므로, 키가 안 나오면 기본 방식(아이가 직접 올리기)으로 하면 됩니다.

## (선택) 부스에 노트북을 두고 자동 인쇄

셀피를 노트북에 연결해 완성 즉시 자동 인쇄하고 싶을 때만 필요합니다(노트북에 Python·Git·Node.js·Codex 설치와 ChatGPT 로그인 필요).
윈도우용 SELPHY CP1500 드라이버를 설치하고 용지를 **엽서(100×148mm)**로 설정한 뒤, 노트북 `.env`에 `BOOTH_PRINTER=SELPHY`를 넣고
`python -m booth print-test`로 확인합니다. 인쇄 사진에는 완성 그림·별명·모습·소개·원본 그림이 함께 들어갑니다.
다시 인쇄: `python -m booth reprint 작업번호`.

## 개인정보·뒷정리

- 아이 이름 대신 **별명**만 받습니다. 사진은 **학습지 그림만** 찍도록 안내합니다.
- 원본 사진은 드라이브에 **비공개**, 완성 그림만 링크 공유. 집 PC에는 `output\booth\날짜\`에 남습니다(저장소에는 안 올라감).
- 행사가 끝나면 드라이브 `캐릭터 공방 (부스)` 폴더와 대기열 시트, 집 PC `output\booth` 폴더를 지우고,
  웹앱은 **배포 관리 → 보관(Archive)** 하면 QR 주소가 더 이상 열리지 않습니다.
