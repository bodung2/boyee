# 캐릭터 공방 (부스 활동)

아이가 학습지에 그린 캐릭터를 폰으로 찍어 보내면, AI가 고른 모습으로 바꿔 **셀피로 인쇄**하고 **패들렛에 올립니다**.
그림은 블로그 일러스트와 같은 방식(**Codex CLI + ChatGPT 구독**)으로 그려서 **API 결제가 없습니다**.

```
아이 폰  ── QR ──▶  웹앱(구글 Apps Script, 로그인 없이 열림)
                     ① 별명  ② 그림 찍기  ③ 모습 고르기(8가지)  ④ 소개(취미·특기, 선택)  → 보내기
                     └─ 드라이브 '원본' 폴더(비공개) + 대기열 시트에 한 줄
부스 노트북 (scripts\run_booth.bat, 창을 켜 두기)
  3초마다 대기열 확인 → ChatGPT(Codex)가 그림을 참고해 새로 그림(1~2분)
  → 결과를 드라이브 '결과' 폴더에 올림 → 아이 폰에 바로 보임
  → 셀피 CP1500으로 엽서 크기 사진 인쇄(완성 그림 + 별명 + 모습 + 소개 + 내가 그린 원본)
  → 패들렛 보드에 글로 올림(키가 있을 때)
큰 화면(TV·빔): 웹앱 주소 뒤에 ?view=wall → 완성 그림이 15초마다 모여 보임
```

**고를 수 있는 모습 8가지:** 🧶 양모펠트 인형 · 🟠 클레이 인형 · 📺 2D 애니메이션 · 🎬 3D 애니메이션 · 🧸 봉제 인형 · 🎮 픽셀아트 게임 · 🎨 수채화 그림책 · 🌟 스티커
(특정 회사·작품 이름은 쓰지 않고 재료·기법으로만 설명합니다. 바꾸려면 `booth/styles.py`, `booth/apps_script/Code.gs`, `index.html` 세 곳을 같이.)

---

## 0. 준비물

- 윈도우 노트북(와이파이) — 집 PC에서 블로그 자동화를 돌리는 컴퓨터를 가져가도 되고, 다른 노트북이어도 됩니다
- 셀피 CP1500 + 엽서 용지·잉크 세트(KP-108IN 등 엽서 크기)
- ChatGPT 구독 계정(블로그에 쓰는 그 계정)
- 개인 구글 계정(@gmail.com 권장 — 학교 구글 계정은 '모든 사용자' 공개·링크 공유가 막혀 있을 수 있습니다)

## 1. 부스 노트북 준비 (처음 한 번, 20분)

**집 PC를 그대로 쓰면** 이미 다 되어 있습니다. PowerShell에서 `cd $HOME\boyee` 후 `git pull` 하고 2단계로.

**다른 노트북이면:**

1. [Python 3.12](https://www.python.org/downloads/)(설치 화면에서 *Add python.exe to PATH* 체크), [Git](https://git-scm.com/download/win), [Node.js LTS](https://nodejs.org/) 설치
2. PowerShell에서:
   ```powershell
   cd $HOME
   git clone -b claude/optimistic-bell-2admac https://github.com/bodung2/boyee.git
   cd boyee
   python -m venv .venv
   .venv\Scripts\python.exe -m pip install -r requirements.txt
   copy .env.example .env
   npm install -g @openai/codex
   codex
   ```
3. `codex`가 열리면 **Sign in with ChatGPT**로 로그인한 뒤 창을 닫습니다(`/quit`).

## 2. 웹앱 만들기 (10분)

1. 개인 구글 계정으로 <https://script.google.com> → **새 프로젝트**, 이름 `캐릭터 공방`.
2. `Code.gs` 내용을 모두 지우고 저장소의 [`booth/apps_script/Code.gs`](../booth/apps_script/Code.gs)를 붙여 넣기.
3. 왼쪽 **파일 +** → **HTML** → 이름을 `index`로(뒤에 .html은 자동). 내용을 지우고
   [`booth/apps_script/index.html`](../booth/apps_script/index.html)을 붙여 넣기. 저장(Ctrl+S).
4. 위쪽 함수 목록에서 **setupBooth** 선택 → **▶ 실행** → 권한 승인('확인되지 않은 앱'이면 고급 → 이동 → 허용).
   아래 **실행 로그**에 `BOOTH_TOKEN=…` 줄이 나옵니다. 드라이브에 `캐릭터 공방 (부스)` 폴더와 대기열 시트가 생깁니다.
5. **배포 → 새 배포 → 웹 앱**
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자** ← 아이들이 로그인 없이 열어야 해서
6. 나온 **웹 앱 URL**(`…/exec`)과 4번의 토큰을 노트북 `.env`에 적습니다:
   ```
   BOOTH_WEBAPP_URL=https://script.google.com/macros/s/…/exec
   BOOTH_TOKEN=(실행 로그의 값)
   BOOTH_TITLE=○○초 축제 캐릭터 공방
   ```

> 나중에 코드가 바뀌면: 두 파일을 다시 붙여 넣고 **배포 → 배포 관리 → 연필 → 새 버전 → 배포**(주소는 그대로).

## 3. 셀피 CP1500 연결 (10분)

1. 캐논 홈페이지에서 **SELPHY CP1500 윈도우용 프린터 드라이버**를 받아 설치하고, 와이파이(또는 USB)로 노트북에 프린터를 추가합니다.
2. 윈도우 **설정 → 프린터 → Canon SELPHY CP1500 → 인쇄 기본 설정**: 용지 **엽서(Postcard, 100×148mm)**, 테두리는 취향대로(테두리 없음 권장).
   방향은 자동으로 맞춥니다.
3. `.env`에 `BOOTH_PRINTER=SELPHY`(이름 일부만 적어도 됨). 그리고:
   ```powershell
   .venv\Scripts\python.exe -m booth print-test
   ```
   예시 캐릭터 사진이 한 장 나오면 성공. 인쇄 위치가 어긋나면 2번의 용지 설정을 확인하세요.

## 4. 패들렛 연결

패들렛 공개 API는 **파일 업로드가 아니라 그림 주소를 붙이는 방식**이라, 결과 그림만 '링크가 있는 사람 보기'로 공유해 그 주소를 붙입니다
(원본 그림은 비공개 그대로).

1. 학교 패들렛 계정으로 로그인 → **설정 → 개발자(Developer)** 메뉴가 있고 **API 키 만들기**가 되면 키를 만듭니다.
2. 부스용 보드를 만들고(서식: 담벼락·그리드 추천), **보드 설정 → 게시물 승인 필요** 를 켜 두면 선생님이 확인한 뒤 공개됩니다.
3. `.env`에:
   ```
   PADLET_API_KEY=(키)
   PADLET_BOARD=https://padlet.com/…/보드이름-abc123xyz
   ```
4. 확인: `.venv\Scripts\python.exe -m booth padlet-test` → 보드에 시험 글이 올라오면 성공(지워 주세요).

**학교(단체) 계정에 개발자 메뉴가 없거나 키가 안 만들어지면:** 패들렛은 공개 API 키를 개인 유료 요금제(Neon·Platinum) 계정에만 주고
단체 계정은 아직 막혀 있다고 안내합니다. 이럴 땐

- `PADLET_API_KEY`를 비워 두면 패들렛 단계만 건너뛰고 나머지(폰 화면·인쇄)는 그대로 됩니다.
- 큰 화면 모아 보기(`웹앱주소?view=wall`)를 TV에 띄워 두고,
- 부스가 끝나면 드라이브 `캐릭터 공방 (부스)/결과` 폴더(또는 노트북 `output\booth\날짜\*_결과.png`)의 그림을 패들렛 보드에
  **한꺼번에 끌어다 놓으면** 그림마다 게시물이 하나씩 생깁니다.

## 5. 리허설 (꼭!)

```powershell
scripts\run_booth.bat --fake
```

`--fake`는 ChatGPT를 쓰지 않고 색만 바꾼 그림을 만들어 **폰 → 인쇄 → 패들렛 흐름만** 연습합니다(구독 사용량 안 씀).
폰으로 QR(아래)을 찍어 그림을 보내 보고, 인쇄·패들렛·큰 화면을 확인하세요.
그다음 `scripts\run_booth.bat`(진짜)로 **10장쯤 연달아** 보내 보며 한 장에 걸리는 시간과 ChatGPT 사용 한도를 확인합니다.

QR 안내판 만들기:

```powershell
.venv\Scripts\python.exe -m booth qr
```

`output\booth\qr_안내판.png`(A4)를 인쇄해 부스에 붙이고, 함께 나오는 **큰 화면 주소**를 TV 브라우저에 띄웁니다.

## 6. 당일 운영

- 노트북에서 `scripts\run_booth.bat` 더블클릭 → 처음에 설정 점검(✅/❌)이 나오고 바로 시작합니다. **창을 끄지 마세요.**
  노트북이 잠들지 않게 전원 설정을 '절전 안 함'으로.
- 한 장에 1~2분. 아이 폰에는 '앞에 N명' → '그리는 중' → 완성 그림이 차례로 보이고, 사진이 프린터에서 나옵니다.
- 줄이 길면 `.env`의 `BOOTH_PARALLEL=2`(동시에 2장). 대신 ChatGPT 사용 한도에 더 빨리 닿을 수 있습니다.
- **다시 인쇄:** 창에 나온 작업 번호로 `.venv\Scripts\python.exe -m booth reprint 1128-103015-ab12`
- **다시 그리기:** 대기열 시트에서 그 줄의 '상태'를 `대기`로 바꾸면 노트북이 다시 가져갑니다.
- 그림이 아닌 사진(얼굴 등)을 보내면 AI가 그리지 않고, 아이 폰에 '캐릭터 그림만 다시 찍어 주세요'가 뜹니다.

## 문제 해결

| 화면·창의 메시지 | 원인 | 할 일 |
|---|---|---|
| ❌ 웹앱 연결 — 토큰이 맞지 않습니다 | `.env` 토큰이 다름 | 편집기에서 setupBooth 다시 실행 → 로그의 토큰으로 |
| ❌ 웹앱 연결 — JSON이 아닌 답 | 배포 액세스가 '나만' | 배포 관리 → 액세스 **모든 사용자** → 새 버전 |
| ⏸ ChatGPT 로그인·사용 한도 문제로 1분 쉽니다 | 로그인 풀림·구독 한도 | 다른 창에서 `codex` 실행해 로그인 확인. 그림은 대기열에 그대로 있어 자동으로 이어집니다 |
| 인쇄 실패: 프린터 '…'를 찾지 못했습니다 | 프린터 이름 다름·꺼짐 | 창에 나온 연결된 프린터 이름 일부를 `BOOTH_PRINTER`에 |
| 패들렛 실패: 공유 주소 없음 | 구글 계정이 링크 공유를 막음(학교 계정 등) | 개인 @gmail.com 계정으로 웹앱을 만들기 |
| 아이 폰이 '부스 컴퓨터가 준비되면…'에서 멈춤 | 노트북 창이 꺼짐·인터넷 끊김 | `run_booth.bat` 다시 실행(받은 그림은 순서대로 처리) |

## 개인정보·뒷정리

- 아이 이름 대신 **별명**만 받습니다. 사진은 **그림만** 찍도록 안내합니다.
- 원본 그림은 드라이브에 **비공개**, 완성 그림만 링크 공유(패들렛·큰 화면용). 노트북에는 `output\booth\날짜\`에 남습니다(저장소에는 안 올라감).
- 행사가 끝나면 드라이브 `캐릭터 공방 (부스)` 폴더와 대기열 시트, 노트북 `output\booth` 폴더를 지우고,
  웹앱은 **배포 관리 → 보관(Archive)** 하면 QR 주소가 더 이상 열리지 않습니다.
